# 0091-4 バグの直しは、再現しないことを確かめ、残すテストは ADR 0091-1 に当たるものだけにする

状態: 採用
日付: 2026-11-24
対象: 全体
置き換える: 0005-1 の1

## 決めたこと

バグは、再現させてから直し、直した後に再現しないことを確かめ、再現のテストを残すのは ADR 0091-1 に当たるときだけにする。

## 捨てた案

1. バグごとに、再現するテストを1つ残す(今のやり方): 表の値や見た目のバグでもテストが増える。バグの数だけ増え続け、0091-1 で絞った基準と食い違う。
2. バグの決まりを消す: 再現させずに原因を推測して直すことを止められない。

## 理由

1. 確認テストは、直したバグが直ったかを確かめるもので、再現する手順を実行して起きないことを見るだけでもよい(ISTQB CTFL v4.0.1 2.2.3、https://www.istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf 。2026-11-24 に読んだ)。
2. 後の変更で壊れないかを確かめる回帰テストとして残すかは、0091-1 と同じ基準で決まる。
