# 0051-1 ファイルでない記録は、手順の文書が作業の結果を書く所に書き、ステータスの行は位置でなく名前で探す

状態: 提案
日付: 2026-11-09
対象: task-team-lead・task-team-se・task-team-pg・task-team-qa
置き換える: 0024-2

## 決めたこと

記録の置き場がファイルでなければ、記録の節は置き場の手順の文書が作業の結果を書く所に書き、書き足す形なら「ステータス: 」の行と節を一緒に書き足して、同じ節とステータスは新しいものを読む。図と画像は手順の文書の添付の仕方で付け、無ければ `docs/tasks/<タスク名>/` に置いて、PL はそのフォルダを消さない。

## 捨てた案

1. 0024-2 のまま、書き足す1行目を「ステータス: 」にする: PL と子セッションは「ステータス: 」の名前で行を探していて、1行目かは見ていない。位置を決まりにすると、型を守ることが目的になる。
2. 0024-2 の決めたことの一部だけを置き換える: 0024-2 の決めたことは番号の付いた項目に分かれておらず、「置き換える: <番号> の<決めたことの番号>」で指せない。

## 理由

1. 同じ節とステータスは新しいものを読むので、行の位置を決めなくても、今のステータスは1つに決まる。
2. atcoder のタスク 0007 で、PL が見せた返事の例の行数を SE が決まりにし、利用者が決めていない形が決まりになった。利用者は、行数は出力の本質ではないと言った。
