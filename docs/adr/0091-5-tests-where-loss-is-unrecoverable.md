# 0091-5 置くテストを、間違うとコードを直しても取り返せない損害が出る計算か判断のものに限る

状態: 採用
日付: 2026-11-24
対象: task-team-test-list
置き換える: 0091-1

## 決めたこと

小と中のテストを、間違うと、お金の額の間違い・法令の違反・見せてはいけない相手に見えた情報・消えたデータのように、コードを直しても取り返せない損害が出る計算か判断に限り、置くテストは、同じ処理を通る値の1組に1つとし、組の境目の値で確かめる(詳しい文は skill `task-team-test-list`)。

## 捨てた案

1. ADR 0091-1 のまま、間違っていても利用者が気づかずに使い続けるものに置く: エラーを出さずに間違うものすべてに当たり、害の大きさを問えない。gemini の 0094 のテスト一覧は、小と中の 61 行のうち 38〜39 行が残った。gemini の標本 101 件は、同じ文でも回ごとに 16〜49 件と割れた。
2. 害の種類を書かずに、直した後も取り返せない損害が出るものに置く: LogiFee の源泉の逆算まで、直せると読まれて落ちた(34 行のうち残るのは 2〜6 行)。
3. 害の種類を括弧で並べて、それに限る: 並べた種類だけと読まれ、権限の無い人に見せない判断と、誤った締切で船積みを逃す計算が落ちた。
4. ADR 0091-1 の捨てた案の1から6は、ここでも捨てた案。

## 理由

1. 利用者の理由: テストが作業のたびに増え続けると困る。過剰なテストはパフォーマンスを落とす。基準は、あるべき形から決める。
2. 定石: テストの範囲と量は、リスク(起きる見込み × 起きたときの害)で決める(ISTQB CTFL v4.0.1 5.2、https://www.istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf)。計算か判断は見込みに、コードを直しても取り返せない損害は害に当たる。ADR 0091-1 は、気づけるかを害の代わりにしたが、気づけるかは害の大きさでない。
3. 試し(2026-11-24。決まりの文書を読まない新しいセッションに、基準の2行とテストの名前の一覧を渡し、3回ずつ分けさせた): gemini の 0094 の 61 行は 5・5・4 行。gemini の標本 101 件は 6・7・6 件。LogiFee は、源泉の逆算・仕訳・売掛金の残・立替の税区分・税込の単価・権限の無い人に見せない判断・人が入れた締切を消さないこと・画面の切り取りのぼかしが残った。
4. 害の種類は、AI が害の大きさを見分けるための例で、並べた4つに限らない。
5. 価値と比べる手間に書く・レビューする時間を含めることと、1組に1つのまま境目の値で確かめることは、ADR 0091-1 の理由4と6のとおり。
