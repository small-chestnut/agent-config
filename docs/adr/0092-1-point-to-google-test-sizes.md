# 0092-1 テストサイズの分け方は、出典の本を指す1行と、本と変える所だけを、いつも読まれる全体の CLAUDE.md に書く

状態: 採用
日付: 2026-11-24
対象: 全体
置き換える: 0009-1

## 決めたこと

テストサイズは、本『Software Engineering at Google』の small・medium・large で分け、画面を操作するテストと速さを測るテストだけは本と変えて large にすると、全体の CLAUDE.md(`claude/CLAUDE.md`)に1行で書く(詳しい文は全体の CLAUDE.md)。

## 捨てた案

1. 分け方を、テストのファイルを読むか書いたときだけ読み込まれる `paths` 付きの規則に置く(今のやり方。タスク 0090 で移した): テストサイズは、テストのファイルを開く前(テスト一覧を書くとき・実行する時の行を読むとき)にも決める。
2. テストサイズに触れる文書(全体の CLAUDE.md・skill `task-team-test-list`・skill `task-team-se`・skill `task-team-pg`)のそれぞれに分け方を書く: 同じ規則は1か所にだけ置く(skill `prompt-structure`)。
3. テストサイズに触れる行から、分け方の文書を読みに行かせる: 読みに行くかが AI の判断になり、読まれないことがある(ADR 0090-2 の捨てた案1と同じ)。
4. 小・中・大の定義の3行を、言い換えずに全体の CLAUDE.md に戻す: 本にある定義の書き直しになる。
5. 本の定義をそのまま使い、localhost で画面を操作するテストを medium にする: ADR 0009-1 の捨てた案2 のまま。
6. テストサイズを、確かめる範囲(単体・結合・端から端まで)で分ける: ADR 0009-1 の捨てた案3 のまま。

## 理由

1. 利用者の理由: 基準を知らないまま、だいたいの見当でサイズを決められては困る。見るべき時に見るべき規則を参照できていないのは、読む量を減らすことより前の問題。明確な出典があるものは、用語集に知られている IT の用語を載せないのと同じで、書き直さなくてよい。
2. 呼び名を small・medium・large にするのは、本の用語だから(ADR 0079-2)。小・中・大は、その用語の言い換え。
3. 本の定義は、資源で分ける(11章、https://abseil.io/resources/swe-book/html/ch11.html 。2026-11-24 に読んだ): small は1つのプロセスで、sleep・ディスク・ネットワークを使わない。medium は1台のマシンで、localhost とだけ通信する。large はその制限が無い。ADR 0009-1 の定義と同じで、違うのは、11章が WebDriver で画面を操作するテストを medium の例に挙げることと、速さを測るテストのサイズを決めていないこと(14章は、ブラウザのテストと速さ・負荷のテストを大きいテストの種類に並べるが、種類ごとのサイズは決めていない。https://abseil.io/resources/swe-book/html/ch14.html 。2026-11-24 に読んだ)。この2つを large にする理由は、ADR 0009-1 の理由3のとおり。
4. 試し(2026-11-24): この1行を3つの新しいセッションに読ませると、3つとも、small・medium・large を本のとおりに答え、後ろの文を本より優先する例外と読んだ。書き換えた全体の CLAUDE.md だけを渡して5つのテストのサイズを聞くと、3つとも、localhost の DB は medium、localhost の画面は large、1つのプロセスで速さを測るのは large、メモリの中の計算は small、一時ファイルは medium と答えた。
5. ADR 0090-2 の基準(特定のファイルを扱うときにしか要らない規則を `paths` 付きの規則に置く)は変えない。分け方は、その基準に当たらないのに移していた。印の2行は、テストのファイルを書くときにしか要らないので残す。2026-11-24 に、`paths` 付きの規則は、合うファイルを Read で開いたときのほか、Write で新しく作ったときと Bash の `cat` で読んだときにも読み込まれた。
6. 同じ基準で、タスク 0090 で移したほかの行(CLAUDE.md・`docs/概要.md`・`.claude/verify-commands.txt` に書くときの行)を見直し、どれもそのファイルに書くときにだけ要るので動かさない。
