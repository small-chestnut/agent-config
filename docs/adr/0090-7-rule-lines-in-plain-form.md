# 0090-7 規則の行の文末を「〜している」から「〜する」に替え、文末の形を決める規則は置かない

状態: 採用
日付: 2026-11-17
対象: 全体

## 決めたこと

規則の行の文末を、状態の形(「〜している」「〜がある」)から、することを言い切る形(「〜する」「〜しない」「〜を置く」)に替え、文末の形を決める規則は置かない。

## 捨てた案

1. 読み違えが起きるかを、何も無いリポジトリで試してから替える: 利用者は、試さずに替えると決めた。替えるだけで字数が減り、読み違えの元も無くなる。
2. 原則・目的・目指す状態の見出しも替える: 見出しは、保つ状態を書く段。替えるのは規則の行だけ。
3. 文末の形を決める規則を置き直す: 今ある行が見本になる。形を決めていた行(規則は「〜でいる」の形で書く)は、タスク 0090 で消してある。

## 理由

1. 利用者の理由: 置き換えるだけで、字数が減る。
2. 状態の形の行は、まだそうなっていないリポジトリで、既にある事実と読み違えられうる(Gemini に全体の CLAUDE.md を読ませたときの指摘。2026-11-17)。読み違えやすいのは、「〜の仕様にある」「コマンドが1行ずつある」のように、ものの有り無しを書いた行。することの形なら、読み違えようが無い。
3. 文末だけを替えた 252 か所は、意味が変わらないので、3つの新しいセッションの確かめ(ADR 0087-1)をしていない。「〜がある」「〜にある」「〜されている」から言い回しを替えた 17 行は確かめ、3つとも意図どおりに読んだ。
4. 事実を書いた行(進行中のチケットは作業ブランチにある、など)は、することでないので、そのままにした。
