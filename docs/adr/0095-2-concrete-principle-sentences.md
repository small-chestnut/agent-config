# 0095-2 AI 側の最適化と人間側の最適化の原則の文を、下の目的が合うかを決められる文にする

状態: 提案
日付: 2026-11-24
対象: 全体
置き換える: 0090-3 の、原則の見出しに置く文のうち、人間側の最適化と AI 側の最適化の文

## 決めたこと

原則の見出しの文を、人間側の最適化は「利用者が、AI の出力と作業の今を、少ない負担で正確につかみ、自分の意図どおりに AI を動かせる」、AI 側の最適化は「Claude が、どのリポジトリでも、要るものだけを読み、手戻りなく、利用者の意図どおりに作業を終えられる」にし、全体の CLAUDE.md とどの skill でも同じ文にする。

## 捨てた案

1. 今の文のままにし、判断できない組の割合が増えたまま受ける: 規則から上へさかのぼるとき、原則の段で判断できず、意図がそこで途切れる(ADR 0095-1 の理由5)。
2. 4段にした目的の文に、原則とのつながりを1つずつ書き足す: 目的の文が長くなり、読む負担が増える。直す文も 100 を超える。
3. AI 側の最適化を「Claude が、どのリポジトリでも、聞き直しと手戻りを少なく、少ない費用で、正しい変更を出せる」にする: 判断できない組は 28/76 と少し少ないが、「聞き直しを少なく」が、分からないことを推測せずに利用者に聞く規則とぶつかる。
4. 安全の原則の文も替える: 判断できない組が 3/5 と少なく、安全の節は損失が取り返しのつかない所(ADR 0090-1 の捨てた案3)。

## 理由

1. 4段にして抽象的な目的を消すと(ADR 0095-1)、具体的な目的が原則のすぐ下に並ぶ。原則の文が広いと、目的が合っているかを原則から決められない。組み直した後の採点(2026-11-24。決まりの文書を読まない新しいセッションに3回採点させ多数決)で、原則→目的の組の判断できない件数は、AI 側の最適化の下が 64/76、人間側の最適化の下が 20/42 だった。
2. 同じ子の目的のまま、原則の文だけを替えて採点すると、AI 側の最適化は 76/76 が 31/76 に、人間側の最適化は 24/42 が 6/42 になった(同じ道具で、同じ日に採点)。
3. 原則の文は、命題「AI 駆動開発の最適化」の2つの面の中身を言うもので、面そのもの(人間側・AI 側)は変えない(ADR 0061-2)。人間側の最適化は、出力をつかむだけでなく、利用者が決めたとおりに AI が動くこと(タスクの進め方・許可・決まりを保つこと)も受け持っていた。AI 側の最適化の「最善の性能」は、読むものを絞ること・手戻りが無いこと・意図どおりに終えることで測る。
4. 利用者の理由: 判断できない割合を、今の割合のまま受けずに、原則の文を替える。
