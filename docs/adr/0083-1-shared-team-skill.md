# 0083-1 役割の受け持ちと全役割が守る規則は共通の skill `task-team` に置き、役割の skill にはその役割でだけ要る規則を置く

状態: 提案
日付: 2026-11-14
対象: task-team・task-team-lead・task-team-se・task-team-pg・task-team-qa・task-team-messaging・add_team_skill_to_team_roles.py

## 決めたこと

task-team の成り立ちと、作業ごとに受け持つ役割の表と、全役割が守る規則を、PL・SE・PG・QA のどの役割も読む共通の skill `task-team` に置き、役割の skill には、その役割でだけ要る規則を置く。

## 捨てた案

1. 役割の skill それぞれに、受け持ちの外の扱いを書き足す(SE に手段を PL に回さない行、PL に SE から決めを求められたら返す行): 同じ境目を2つの skill に書くので、片方だけ直されてずれる。ほかの役割が何を受け持つかは、どの skill からも見えないまま残る。
2. skill `task-team-messaging` の名前のまま、中身を足す: 名前が、知らせ方だけでなく受け持ちの表も持つ中身を言い表さない。
3. 共通の skill を読む指示を、役割の skill の行に書く: 役割の skill を読んだ直後に必ずする作業なので、フックがする(ADR 0071-1)。

## 理由

1. LogiFee の R-0784 のチーム(2026-11-13〜14)で、SE は手段の決めを PL に求め、PL は自分の判断で答えて SE の方針を変えさせ、そのうち1つは誤りだった。どちらの skill も自分の役割の受け持ちだけを書き、相手の役割の受け持ちを書いていなかった。
2. 1枚の表を全役割が読めば、どの作業をどの役割が受け持つかが、どの役割からも同じに見える。
3. 利用者は、チーム全体として何かを書いた共通の skill と、その役割でだけ要る規則を持つ役割の skill に切り分ける形を選んだ。
