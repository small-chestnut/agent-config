# 0047-2 ほかのリポジトリで気づいた全体の規則のずれは、install が書き残した agent-config の本体の作業ツリーに、ずれ1件につき「未着手」のチケット1つを、コミットせずに足す

状態: 採用
日付: 2026-11-09
対象: 全体

## 決めたこと

agent-config の外で全体の CLAUDE.md・skill の規則のずれに気づいた AI は、install が設定ディレクトリの `agent-config-path.txt` に書き残した agent-config の本体の作業ツリーの `docs/tasks/` に、ずれ1件につきステータス「未着手」のチケット `<英語の短い名前>.md` を、コミットせずに1つ足す。番号を振ってコミットし、push するのは agent-config の PL(ADR 0047-3。詳しい文は全体の CLAUDE.md の原則3)。

## 捨てた案

1. 返答に、agent-config の PL へ貼って送る1行を付ける: 利用者が選ばなかった。ずれを運ぶ役が利用者に残る。
2. Notion の ✅ Todo に行を作る: Notion につながっていない会話(会社のアカウントなど)からは届かない。
3. agent-config の GitHub に issue を立てる: 作業中のリポジトリの場面が、公開の issue に出る。チケットと別の置き場も増える。
4. 届いたずれを1つのファイルに並べる: 利用者が、ずれ1件にチケット1つを選んだ。
5. ほかのリポジトリの AI が、agent-config にコミットして push まで済ませる: agent-config の作業ツリーのブランチや未コミットの変更は、その場からは分からず、PL の作業とぶつかる。
6. agent-config の場所を、全体の CLAUDE.md に書くか、毎回利用者に聞く: 場所は PC ごとに違い、聞くたびに利用者の手が要る。

## 理由

1. 利用者の理由: `~/.claude` の写しを直しても、次の install で上書きされて消える。ずれが agent-config に届かないと、矛盾を探して突きつける役が利用者に残る(ADR 0046-3 の理由4 で範囲外にした部分)。
2. 場所を install に書かせるのは、install はその PC の agent-config から走るので、場所を必ず知っているから。本体の作業ツリー(`git worktree list` の1行目)を書くのは、worktree から走らせても、その worktree はマージ後に消えるから。
3. チケットに作業中のリポジトリのコードとデータを写さないのは、agent-config は公開のリポジトリで、チケットは既定のブランチに push されるから。
