# 0011-2 確かめのコマンドの頭は、各リポジトリの `.claude/verify-commands.txt` に1行ずつ書く

状態: 採用
日付: 2026-10-31
対象: 全体

## 決めたこと

確かめのコマンド(テスト・lint)の頭を、各リポジトリの `.claude/verify-commands.txt` に1行ずつ書き、その頭で始まるコマンドが通れば、その確かめが通ったとみなす。

## 捨てた案

1. リポジトリ直下の CLAUDE.md の、テストと lint の行から、コマンドを読み取る。
2. 頭ではなく、コマンドの全文が一致したときだけ通ったとみなす。

## 理由

1. CLAUDE.md は人と AI が読む文で、形が決まっていないため、読み取りが崩れやすい。公式の手引きも、コマンドを CLAUDE.md に書くことと、Stop フックで守らせることを別に書いている(https://code.claude.com/docs/en/best-practices)。
2. 書いている間に流すのは、変えた所の小さいテストだけ(README のテストを流す時と量)。全文の一致では、テストを絞って流すたびに一覧と食い違う。
