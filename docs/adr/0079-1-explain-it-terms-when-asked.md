# 0079-1 IT の用語は、意味を添えずにそのまま使い、利用者に問い返されたときに意味を説明する

状態: 提案
日付: 2026-11-13
対象: 全体
置き換える: 0044-1

## 決めたこと

IT の用語がある概念は、例えや作った呼び名に置き換えずにその用語で書き、意味は、初めて出すときに添えず、利用者に問い返されたときに説明する(詳しい文は全体の CLAUDE.md)。

## 捨てた案

1. 今のまま、知らない人には初めて出すときに意味を添える(ADR 0044-1): 利用者がどの用語を知っているかは、どこにも残っていない。初めて出すかも、会話を圧縮した後と、ほかのセッションで利用者が読んだものは見えない。AI は条件を推測で当て、毎回添えて返答が長くなるか、推測で省くかになる。
2. IT の用語を出すたびに意味を添える: 利用者が知っている用語にも添えるので返答が長くなり、1ターンの返答をスクロールせずに読み切れる、に逆らう。
3. 利用者が知っている用語を自動メモリに書き溜めて当てる: 記録は増え続け、ほかの PC とほかのアカウントの設定ディレクトリでは揃わない。

## 理由

1. 問い返されたことは、AI に見える。見分けられない条件を、見える出来事に替えられる。
2. IT の用語は、画面やエラーメッセージにも同じ語で出て(例: メーラの IMAP 設定)、利用者が調べることもできる。言い換えると、画面の語と結びつかない。
3. 利用者は、最初はその用語をそのまま使い、問い返されたときに初めて説明すればよいと決めた。
