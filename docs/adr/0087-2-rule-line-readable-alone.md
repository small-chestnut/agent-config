# 0087-2 規則の1行は、その1行だけを読んで利用者が意味を分かる文にする

状態: 提案
日付: 2026-11-15
対象: prompt-structure

## 決めたこと

skill `prompt-structure` の目的「利用者が、全部を見張らなくても、プロンプトを思いどおりに保てるようにする」の下に、目指す状態「規則の1行は、その1行だけを読んで、利用者が意味を分かる」を置く。

## 捨てた案

1. LogiFee のように、新しい目的「利用者が、決まりを読んで管理できる」を立てる: 今ある目的が同じことを言っている。1行ずつ読めることは、全部を見張らずに保つための状態として、今ある目的から導ける。
2. 今ある規則の行を、今まとめて読み直す: 利用者がタスクに入れていない。規則の行を足す・直すときに確かめる。
3. 全体の CLAUDE.md に置く: 規則を書くときにだけ要る決まりで、規則を書く前に読む skill `prompt-structure` にあれば足りる。毎回読む CLAUDE.md の字数(上限 8,000 字・ADR 0076-1)を使わずに済む。

## 理由

1. 規則を管理するのは利用者で、その1行だけで読めない規則は、Claude に効いていても、残すか直すかを利用者が決められない。
2. LogiFee で消した「ものを指す語に、日常の物の名前を例えとして使っていない」の行は、3つのセッションのどれもが意図と違う意味に読んだ(R-0830)。
3. 規則の行は 60 字までなので、見出しやほかの行に頼って言葉を省きやすい。LogiFee では、分野の名前を2つ上の行に任せて省いた行が、意図と違う意味に読まれた。
