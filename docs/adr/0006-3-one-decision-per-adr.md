# 0006-3 1つの ADR には決定を1つだけ、どの決定かが分かる1行で書く

状態: 採用
日付: 2026-10-31
対象: 全体

## 決めたこと

1つの ADR には決定を1つだけ書き、「決めたこと」はどの決定かが分かる1行にして、詳しい文は skill などの決まりを書く文書に任せる。

## 捨てた案

1. 1つの ADR に、関わる決定をいくつも番号付きで書く(0004-1・0005-1 の形)。
2. 「決めたこと」に、決まりを書く文書と同じ詳しい文を書く。

## 理由

1. 決定が1つなら、決めた所の番号から読む ADR が、その所の決定だけになる。決定がいくつもあると、関わらない決定まで読む。
2. 詳しい文が決まりを書く文書と ADR の2か所にあると、読む量が増え、片方だけ直すと食い違う。
