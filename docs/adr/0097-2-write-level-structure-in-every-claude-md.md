# 0097-2 段の構成とその意図を、全体の CLAUDE.md と、どのリポジトリの CLAUDE.md にも書く

状態: 採用
日付: 2026-11-24
対象: 全体

## 決めたこと

上の段から下の段を導いて書くことと、段に分ける意図を、全体の CLAUDE.md と、どのリポジトリの CLAUDE.md の冒頭にも書く(見本は `claude/rules/claude-md.md`)。

## 捨てた案

1. 全体の CLAUDE.md だけに書く: agent-config を使っていない人の Claude は読まない。LogiFee の CLAUDE.md だけを新しいセッションに読ませると、段の関係も段に分ける意図も、文を根拠に答えたのは 0/3(冒頭に足すと 3/3)。
2. skill `prompt-structure` だけに置く(前の形): 決まりを書く・直すときにしか読まれない。全体の CLAUDE.md を読ませても、上の段が下の段を導くと文を根拠に答えたのは 0/3(足すと 3/3)。
3. 段を Why・What・How で説明する表を書く: 表だけを足しても、上の段が下の段を導くと文を根拠に答えたのは 0/3。利用者も、表を一つの目安とした。
4. ほかの人も使うリポジトリだけに書く: 利用者は、全部のリポジトリに書くと決めた。

## 理由

1. 利用者の理由: 命題が原則を、原則が目的を、目的が規則を導くことが、今の文からは分からない。agent-config を使っていない人の Claude は、リポジトリの CLAUDE.md に無いと、構成とその意図を読み取り切れない。
2. 同じ文が全体の CLAUDE.md と、どのリポジトリの CLAUDE.md にも載る。同じ規則を1か所にだけ置く決まり(skill `prompt-structure`)の例外になり、段の構成を変えるときは、どのリポジトリの CLAUDE.md も直すことになる。
3. 試しは、2026-11-24 に `claude-opus-5-5` の新しいセッションに3回ずつ読ませた、読み取りの確かめ。実際の作業の判断が変わるかは確かめていない。
