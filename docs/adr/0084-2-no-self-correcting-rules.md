# 0084-2 AI が規則を目的に照らして直す・消すことを期待せず、そうさせる規則を置かない

状態: 採用
日付: 2026-11-14
対象: 全体
置き換える: 0046-2・0046-3 の、規則を目的に照らして直す・消す所・0048-1 の、全体の規則を点検する場所

## 決めたこと

AI が規則・仕様・コードを目的に照らして直す・消す(自浄する)ことを期待せず、そうさせる規則を、全体の CLAUDE.md・skill `prompt-structure`・このリポジトリの CLAUDE.md から消す(規則の理由を聞かれたときの答え方の規則も消す)。ADR 0046-3 のうち、規則・仕様・コードを今の手段として読むことと、手段が目的とぶつかったら目的に従うことは、直す・消すことでないので残す。

## 捨てた案

1. 前もって照らす規則(ADR 0046-3)を残し、働かない原因を突き止めて直す: 利用者は、AI に自浄を期待しないことを選んだ。
2. 規則の理由を聞かれたときの答え方の規則(ADR 0046-2)だけを残す: 聞かれてから働く規則で、利用者が先に疑いを持った後にしか効かない。利用者に要るのは、聞かれる前から規則がそぐわないと判断できることで、この規則はそれを生まない。

## 理由

1. 利用者の理由: 大事なのは、理由を聞かれてから規則が要らないと答えることでなく、聞かれる前から、規則が利用者のやりたいことにそぐわないと判断して消せること。前もって判断する規則(ADR 0046-3)は、実際には全く働いていない。
2. 働いていない例: 下に規則の行の無い「失敗する条件」の見出しは、2026-10-21 から 0084 で利用者が指摘するまで、どの AI にも直されなかった。0084 の SE も、説明の規則を洗い出したとき、利用者が曖昧で理解しがたいと言う3つの規則を「残す」と見立てた。
3. ADR 0048-1 のうち、作業が進まないときに目的に従って進めることと、それを報告に書くことは、規則を直す・消すことでないので残す。全体の規則を点検する場所(agent-config で作業するときだけ)は、点検そのものをさせないので消す。
4. ADR 0063-1(手段は利用者に選ばせず、AI が目的と「なぜ」から導く)は、規則を直すことでなく、利用者に何を聞くかの決定なので残す。ADR 0046-3 の残す2行と一緒に、全体の CLAUDE.md の人間側の最適化の新しい目的「利用者が、目的と「なぜ」を決めるだけで済む」の下に置き直す。ADR 0063-1 の理由1 と ADR 0046-3 の理由1 は、どちらも利用者の負担の理由で、人間側の最適化に当たる。
5. skill `prompt-structure` の「Claude が規則に手を入れるのは…」の行は、「規則が目的に反するとき」を消し、「ほかの規則がそうさせるとき」を足す。全体の CLAUDE.md の、利用者しか使わないリポジトリの決まりを書き直す行(ADR 0049-1)は、「違う」と言われずに規則を書き直させる。
