# 0057-1 PL は、PG と QA のセッションを、表示を切ったサイドバーの区切りへ移す

状態: 廃止
日付: 2026-11-10
対象: task-team-lead

## 決めたこと

PL は、起こした PG と QA のセッションを、利用者が表示を切ったサイドバーの区切り「PG と QA」へ移し、サイドバーには PL と SE だけを出す。

## 捨てた案

1. PG と QA を、SE の中で動くサブエージェントにする: 利用者が開いて止めたり口を挟んだりできなくなり、PG が利用者に操作を頼むタスクで、利用者が PG と話せない。
2. PG と QA を、起こしたらすぐアーカイブする: アーカイブはセッションを止めるので、SE と QA からの `SendMessage` を受けて動けなくなる。
3. 今のまま、PG と QA もサイドバーに出す: 利用者が直接話さない行が、タスクごとに2つずつ一覧に積もる。

## 理由

1. 利用者がタスクで話すのは PL と SE だけで、PG と QA は PL の会話のリンクから開ければよい、と利用者が決めた。
2. セッションのままなので、`SendMessage` での受け渡しと、「利用者待ち」の行のリンクから開く道は、今のまま残る。
3. アプリの道具の説明では、利用者が表示を切った区切りは描かれない(`list_sections` の `shown`)。表示を切るのは利用者がサイドバーで一度するだけで、どのリポジトリの PG と QA も同じ区切りに入れられる。
4. 利用者が目にする行を、話す相手だけに絞ると、利用者が AI の出力をつかむときの認知負荷が下がる。
