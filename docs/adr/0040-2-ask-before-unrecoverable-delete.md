# 0040-2 消す前に利用者へ伝えるのは、git から戻せないものだけにする

状態: 提案
日付: 2026-11-07
対象: 全体

## 決めたこと

対象と理由を利用者に伝えてから消すのは、まだコミットしていないものと、リポジトリの外のものだけにし、git にコミット済みのものは伝えずに消す。

## 捨てた案

1. 今のまま、どの削除でも先に伝える: AI しか見ていないテストやコードの消し方を聞かれても、利用者には判断材料が無い。伝える手間が、消さずに残す方へ AI を寄せる。
2. どの削除も伝えない: まだコミットしていないものとリポジトリの外のものは、消すと戻せない。

## 理由

1. 利用者が判断できるのは、見えている仕様、つまりどの機能を残す・変える・消すかまで。機能を消すかは、今どおり利用者が決める。
2. その先のテストやコードを消した変更が正しいかは、利用者ではなく、別のセッションのレビューとテストで確かめる。一般の開発でも、コードを消した変更はコードレビューで確かめる。
3. git にコミット済みのものは、消しても履歴から戻せる。聞かずに消しても、原則1 の目的(何を変えても、元に戻せる形で作業する)は守れる。
