# 0048-1 ほかのリポジトリの AI は全体の規則を点検せず、全体の規則のとおりでは作業が進まないときだけ、その親の目的に従って進め、報告に書く

状態: 採用
日付: 2026-11-09
対象: 全体
置き換える: 0047-1・0047-2

## 決めたこと

agent-config の外で作業する AI は、全体の CLAUDE.md・skill の規則をその親の目的・目指す状態に照らして点検せず、ずれのチケットも作らず、全体の規則のとおりでは作業が進まないときだけ、その規則の親の目的・目指す状態に従って進め、従わなかった規則とどう動いたかを利用者への報告に書く(全体の規則の点検は agent-config の中で ADR 0046-3 のとおりにする。詳しい文は全体の CLAUDE.md の原則3)。

## 捨てた案

1. 今のまま、ほかのリポジトリで気づいたずれを agent-config のチケットにする(ADR 0047-2): その作業に要らない点検をさせる。2026-11-09 に gemini の AI が、リポジトリの決まりとぶつかっただけのもの(ADR 0004-1 で片付くもの)をずれと読んだチケットを2つ置き、利用者が問いただしてやめさせた。
2. チケットは作らず、気づいたずれを報告に書く: 点検そのものが残るので、読むものが作業に要るものに絞られず、見間違えたずれを問いただす役も利用者に残る。
3. 全体の規則のとおりでは作業が進まないときは、止まって利用者に聞く: 目的と目指す状態を、規則に無い場面でも AI が意図に沿って動けるように置いた意味が無くなる(ADR 0047-1 の理由1)。

## 理由

1. 利用者の理由: ほかのリポジトリの作業中は、AI にそのリポジトリのことだけを考えさせたい。全体の規則の点検はその作業に要らず、全体の CLAUDE.md 原則3 の「1つの作業で読むものが、その作業に要るものに絞られている」に反する。ADR 0047-1・0047-2 は、この目指す状態と照らしていなかった。
2. 前の理由 → 新しい理由: 「ずれが agent-config に届かないと、矛盾を探して突きつける役が利用者に残る」(ADR 0047-2 の理由1) → 「ほかのリポジトリの AI に点検させると、AI が見間違えたずれを問いただす役が利用者に残る。点検は agent-config の中でする」。利用者は、AI の矛盾を突くこの作業が一番しんどいと言っている。
3. 点検の場所は既にある: agent-config で作業するときは、全体の CLAUDE.md・skill もそのリポジトリの中の手段なので、ADR 0046-3 で AI が目的に照らして直す。
4. 作業が進まないときに目的に従って進めることと、それを報告に書くことは残す: 前者は ADR 0047-1 の理由1 のとおり。後者は、AI が規則と違う動きをしたことを利用者が知れるようにするため。
5. install が設定ディレクトリに agent-config の場所を書く仕組み(ADR 0047-2 の理由2)は、ずれのチケットを足すためだけにあったので、一緒に消す。
