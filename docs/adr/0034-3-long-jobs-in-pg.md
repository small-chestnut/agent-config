# 0034-3 本番で長く動かす処理は、PL ではなく、そのタスクの PG が始めて持つ

状態: 採用
日付: 2026-11-04
対象: task-team-lead

## 決めたこと

本番で長く動かす処理は、PL が始めず、そのタスクの PG が始めて終わるまで持つ。

## 捨てた案

1. PL が始める(2026-11-04 の LogiFee の形): 背景のシェルは始めたセッションに付くので、PL を替えても元のセッションを処理が終わるまで閉じられず、PL が作業する間はチームの知らせが待たされた。
2. 処理ごとに新しいセッションを起こす: サイドバーの行が増える。利用者は PG を選んだ。

## 理由

1. PL がいつでも返事ができれば、利用者との会話も子セッションの知らせも待たされない。
2. 本番の処理は実装の手順の1つで、PG はもとから設計の手順を実行するセッション。
