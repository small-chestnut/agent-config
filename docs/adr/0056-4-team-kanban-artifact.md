# 0056-4 全部のタスクの進み具合は、利用者のアカウントに1枚あるかんばんで見せる

状態: 採用
日付: 2026-11-10
対象: task-team-lead・task-team-se・task-team-messaging・team-kanban・team-kanban-page
置き換える: 0035-1 の、PL が図を描いて出す所

## 決めたこと

PL は、全部のリポジトリのタスクの進み具合を、利用者の claude.ai のアカウントに1枚ある Artifact のかんばん(リポジトリごとのタブ・段階ごとの列・タスクごとのカード)に、チケットから書き直して見せる。タスクの中のサブタスクの図は、聞かれた SE が描く。

## 捨てた案

1. PL が、聞かれるたびに、会話の中にタスクごとの図を描く(0035-1 の形): PL が毎回 HTML を書くので細かい所がぶれ、描くたびにその HTML が PL の会話に入る。タスクをまたいだ全体が、1枚で見えない。
2. 進み具合を、リポジトリの1ファイルで管理する: 進み具合が変わるたびに、既定のブランチへのコミットが要る。元がチケットと2か所になり、ずれる。
3. かんばんを、リポジトリごと・PC ごとに分ける: 見た目を揃えるには、同じページをかんばんの数だけ保つことになる。利用者は、ほかの PC で進めているタスクも、同じかんばんで見たい。
4. 1つの画面に、全部のリポジトリを並べる: 一度に目に入るカードが増える。タブなら、見ているリポジトリのカードだけが出る。

## 理由

1. タスクをまたいだ進み具合を、段階の列とカードで見せるのは、かんばんの定石(Jira・GitHub Projects のボード)。0035-1 がかんばんを捨てたのは、タスクの中のサブタスクのつながりが見えないからで、そこは SE が描く図に残す。
2. Artifact は利用者のアカウントにあるので、どの PC からも同じかんばんが開き、ほかの人のアカウントからは見えない。
3. ページの作りは1つに固定し、PL が書き換えるのはカードのデータだけなので、見た目がぶれない。
4. カードは、既定のブランチとリモートの作業ブランチにあるチケットから作れるので、かんばんが消えても作り直せる。
