# 0011-3 画面が変わる変更は、AI が動かした画面のスクリーンショットを見て確かめ、報告にその画像を付ける

状態: 採用
日付: 2026-10-31
対象: 全体

## 決めたこと

画面が変わる変更は、AI が動かした画面のスクリーンショットを撮って見て確かめ、終わったという報告にその画像を付ける。

## 捨てた案

1. 画面を見たかも、フックで機械的に確かめる。
2. 画面の確かめを、画面を動かす大きいテスト(CI で流す)だけに任せる。

## 理由

1. どの変更で画面が変わるかと、スクリーンショットを撮る道具(内蔵のブラウザ・Claude in Chrome・`/verify` など)は、リポジトリと環境ごとに違い、機械の条件にできない。
2. 大きいテストは決めた操作の結果しか見ず、崩れた配置や読めない字は見落とす。公式の手引きは、ブラウザのスクリーンショットを AI が自分の仕事を確かめる手段に挙げ、証拠として画像を求めるよう勧めている(https://code.claude.com/docs/en/best-practices)。
