# 0097-4 SE は、効くか逆効果かを答えず、命題・原則・目的に反すると思ったときだけ待ったをかける

状態: 提案
日付: 2026-11-24
対象: task-team-se

## 決めたこと

SE は、依頼や要件がリポジトリの目的に効くか逆効果かを答えず、命題・原則・目的に反すると思ったときだけ、反する段と理由を利用者に伝え、利用者が進めると言うまで設計を始めない。

## 捨てた案

1. 最初のターンで、効くか逆効果かを根拠つきで答える(前の形): 利用者は、効くかどうかの応答を要らないとした。
2. 反すると思ったら、懸念を1行添えて進める(前の形): 利用者が求めたのは、待ったをかけること。

## 理由

1. 利用者の理由: 効くかどうかの応答は要らない。命題・原則・目的に反すると思ったときに待ったをかけてくれれば足りる。
2. 前の形を入れたときの理由(理解が曖昧なまま、AI 駆動開発に逆効果なタスクが走り始めるのを防ぐ。2026-11-01 のタスク 0018)は、反するときに止めることで満たせる。
3. 壁打ちをしないタスク(エラーを直す依頼と、PL が聞かずに進めると添えたタスク。ADR 0056-2)でも止める。反すると思わないタスクは、今までどおり聞かずに設計を始める。
