# 0098-2 段の見出しの書き方の文は skill `prompt-structure` に置き、フックはそれを指して問う

状態: 採用
日付: 2026-11-24
対象: ask_about_written_lines.py・check_rule_documents_changed_by_shell.py・prompt-structure
置き換える: 0061-1 の、導いたかをフックが問い返す所

## 決めたこと

原則・目的の見出しを書いた保存では、フックが、skill `prompt-structure` の段の書き方に照らすことを問い返し、書き方の文はフックに置かない。

## 捨てた案

1. フックの文を今のまま残し、skill にも同じ文を置く: 同じ規則が2か所になり、片方だけを直すと食い違う(skill `prompt-structure` の「同じ規則は、文書をまたいでも1か所にだけ置く」)。
2. フックの段の問いを消す: 保存したその場で見直させる時が無くなる(ADR 0061-1 の捨てた案4)。
3. 文をフックだけに置いたままにする(前の形): フックは保存した後にしか問わない。案は会話とチケットに書かれ、利用者が合意した後に保存されるので、案を書くときには届かない(Gemini の 0099 では、案を書く間に1度も問われなかった)。
4. フックがチケットの保存でも問うようにする: チケットには段の見出しを図や表や引用でも書くので、見出しの行では見分けられない。

## 理由

1. 案を書く前に読むのは skill `prompt-structure` で、0099 の SE も案の前に読んでいた。書き方の文がそこにあれば、最初の案から効く(ADR 0098-1 の理由2)。
2. 保存したときの問いは、見出しを書き換えた PG にも、書き方に照らす時を作る。書き方そのものは、skill の1か所から読む。
