# 0090-3 上の段ほど先に守ると書き、命題と原則の文を、どのリポジトリでも読まれる所に置く

状態: 採用
日付: 2026-11-17
対象: 全体

## 決めたこと

全体の CLAUDE.md の冒頭に、命題と、命題・原則・目的・目指す状態・規則の順に先に守り上の段に反する下の段が誤りだという行を置き、原則の見出しには、名前のあとに、その原則を果たした姿の1文を置く。

## 捨てた案

1. 「子の段を全部果たすと、親の段が果たせる」と書く: 規則を全部守れば上の段が守られるように読め、規則が主になる(利用者の指摘)。
2. skill ごとに命題を置く: skill は全体の CLAUDE.md と一緒に読まれる。同じ文は1か所に置く。
3. 「<すぐ上の段>とは、<その段>である」と言える文にする規則を置く: 上の段が下の段を包含する行と、守る順の行から導ける。

## 理由

1. 利用者の理由: 一番に守るのは命題で、命題に反する原則は原則が誤り。次に守るのは原則で、原則に反する目的は目的が誤り。下の段も同じ。
2. 命題は README にしか無く、ほかのリポジトリでは読まれなかった。全体の CLAUDE.md も skill も原則から始まり、いちばん上の段が欠けていた。
3. 原則の名前(人間側の最適化など)だけでは、何を指すかが分からない(利用者の指摘)。置いた文は、安全が「AI の操作で、利用者が取り返しのつかない損失を負わない」、人間側の最適化が「利用者が、AI の出力を、少ない負担で正確につかめる」、AI 側の最適化が「Claude が、どのリポジトリでも最善の性能を出せる」。
4. 置いた文は、決まりの文書を読まない3つの新しいセッションが、同じ意味に読んだ(ADR 0087-1)。
