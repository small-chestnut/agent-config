# 0099-1 今ある文書の目的は、文だけを言い換えず、文書ごとに原則から導き直して規則を置き直す

状態: 採用
日付: 2026-11-25
対象: 全体

## 決めたこと

全体の CLAUDE.md・`claude/rules`・skill の目的を、skill `prompt-structure` の段の書き方(ADR 0098-1)に照らして見直すときは、文書ごとに、原則から目的を導き直し、今ある規則を文を変えずにその目的の下へ置き直し、目的の見出しにあったやり方は規則に移す。

## 捨てた案

1. 基準に合わない目的 60 の文だけを、その場で言い換える: 目的が、5段だったときの目指す状態ごとに1つずつ並んだままになり、原則の下の置き間違い(人間側の最適化の目的が AI 側の最適化の下にある、など)も残る。
2. 基準に合わない目的が 0 になるまで、文を替え続ける: 残った5つは、どれも、同じ文で、採点の回によって合う・合わないが変わった(合わないものは、回によって 3〜5)。
3. 見出しにあったやり方を、規則に移さずに消す: 下に規則が無かった目的の中身(QA の指摘の根拠など)が、どこにも残らない。
4. 原則の文も変える: 原則から合うかを決められない目的は 18 から 2 に減り、原則の文(ADR 0095-2)のままで足りる。

## 理由

1. 利用者の理由: 2つのやり方(この決定と、捨てた案1)を、skill `task-team-pg` を組み直した見本と採点の結果を見比べて、組み直しを選んだ。
2. 採点(2026-11-25。0098 と同じ基準で、文書の由来を知らない新しいセッション(`claude-opus-5-5`)に3回ずつ採点させた多数決):

   | | 組み直す前 | 組み直した案 |
   |---|---|---|
   | 目的の数 | 126 | 114 |
   | 基準に合わない目的(手段を決めている・なぜ必要か分からない・どうなっていればよいか分からない、のどれか) | 60 | 5 |
   | 原則から合うかを決められない目的 | 18 | 2 |
   | 目的から合うかを決められない規則 | 140/387(36%) | 96/399(24%) |
   | 5段だったときの目指す状態とほぼ同じ文の目的 | 74 | 20 |

   ADR 0098-1 の試しでは、目的から規則を決められない割合は変わらなかった。規則を置き直すと、下がった。
3. 規則の文は、見出しから移した 12 行と、目的の名前を引用する1行と、この ADR の番号を付けた1行と、原則が2つになる文書に足す「原則がぶつかったときは、番号の小さい方を先にする。」の行のほかは変えない。目的の組み直しと規則の中身の変更を、1つの変更に混ぜない。
4. `restructure-modules` の目的は、動きの変わった所の見落とし・コンフリクト・参照のずれで、取り返しのつかない損失ではなく手戻りなので、安全から AI 側の最適化に移す。
5. 前の見出しの中身が残っているかも、新しいセッションに3回答えさせた。失われたのは細かい限定(テストサイズが資源で決まること・ADR が「採用した」ものであることなど)で、残りの規則と出典の本が同じ動きをさせる。
6. 採点も Claude がした。
