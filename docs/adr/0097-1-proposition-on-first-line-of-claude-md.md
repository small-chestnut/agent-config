# 0097-1 リポジトリの命題は、リポジトリ直下の CLAUDE.md の1行目に置く

状態: 採用
日付: 2026-11-24
対象: 全体
置き換える: 0084-5 の、命題をリポジトリの目的を書く文書の冒頭に置く所・0090-1 の、2つ目の命題を README に置く所

## 決めたこと

リポジトリの命題(システムを作る理由)は、リポジトリ直下の CLAUDE.md の1行目に「命題」と書いて置き、`docs/概要.md` には誰が使うかと機能の一覧を残す。

## 捨てた案

1. `docs/概要.md` の冒頭に置く(前の形): 自動では読まれない。新しいセッションに全体と LogiFee の CLAUDE.md だけを読ませると、LogiFee の命題を答えたのは 0/3(CLAUDE.md の1行目に「命題:」を足すと 3/3。2026-11-24、`claude-opus-5-5`)。
2. CLAUDE.md から `docs/概要.md` を読み込む(`@` で取り込む): 機能の一覧まで毎回読む。
3. CLAUDE.md と概要の両方に置く: 片方だけを直すと食い違う(ADR 0084-5 の捨てた案1)。

## 理由

1. 利用者の理由: コンテキストに常時入る所に、明示的に「命題」と書かないと、命題として読まれない。
2. ADR 0084-5 の理由1も、命題をいつも読まれる文書に置くと言う。置き場所だけが、いつもは読まれない文書になっていた。
3. agent-config の2つ目の命題(ADR 0090-1)は README にしか無く、CLAUDE.md は README を指すだけだった。命題の文は変えずに、agent-config の CLAUDE.md へ移す。README には、命題の面と制約条件と原則の順(ADR 0061-2)と「なぜ」を残す。
