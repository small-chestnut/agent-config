# 0010-2 仕様に、そのモジュールを縛る ADR の番号を並べる

状態: 採用
日付: 2026-10-31
対象: 全体

## 決めたこと

仕様の「ADR」の節に、そのモジュールの仕様の行・コード・CLAUDE.md に付いた ADR の番号を並べ、SE はモジュールのコードを書き換えるとき、そこに並んだ番号の ADR も読む。

## 捨てた案

1. 今のまま、モジュール・テスト・lint の設定を「ADR」で検索して、コードに付いた番号を集める(0006 で入れたやり方)。
2. コードの番号を、1か所でなく、決定が効くファイルすべてに付ける。

## 理由

1. 0006 の QA の設計レビューの指摘: コードでは番号が lint の設定やテスト名など1か所にしか付かず、別のファイルを書き換える SE がたどり着けないことがある。案1の検索は、検索した場所の外に付いた番号を拾えない。
2. 案2では、決定が効くファイルが増えるたびに番号を付け足すことになり、付け忘れが増える。
3. 仕様は SE が設計の最初に必ず読むので、並べた番号に必ず行き着く。読む ADR の数は、そのモジュールを縛る ADR の数で決まり、ADR の総数によらない(ADR 0006-1 の理由と同じ)。
