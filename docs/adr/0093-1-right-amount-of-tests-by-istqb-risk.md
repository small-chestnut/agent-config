# 0093-1 テストが適正な量になることを目指し、作るテストと残すテストは、ISTQB CTFL シラバスのリスクベースドテストで決める

状態: 提案
日付: 2026-11-24
対象: task-team-test-list
置き換える: 0091-5

## 決めたこと

目指す状態を、テストが適正な量になっていることとし、作るテストと残すテストは、ISTQB CTFL シラバスのリスクベースドテストで決める(詳しい文は skill `task-team-test-list`)。

## 捨てた案

1. ADR 0091-5 のまま、損害の種類を並べた「コードを直しても取り返せない損害」で決める: Claude が引いた線で、参照する文献が無い。gemini の 0094 では、衣装を着て描く主な使い方のテストまで落ちる。
2. 目指す状態を変えずに、基準の行だけを文献の名前にする(0094 の 61 行のうち 29〜43 行が残る): 見出し(価値が、書く・レビューする・直す・実行する手間を大きく上回るものだけ)が、Khorikov の本の言い換えになる。
3. 文献の名前だけを書き、目指す状態を書かない: 0094 の 61 行のうち、本『Software Engineering at Google』だけなら 59〜60 行、Khorikov の本だけなら 50〜52 行、ISTQB CTFL だけなら 54〜57 行が残る。何のためにリスクを見るかが無く、害の小さいリスクにもテストを置く。
4. リスクレベルの高いプロダクトリスクにだけ置き、ほかは受容するという線を足す(0094 は 13〜19 行): 線は文献に無く、Claude が引いた線になる。数を減らすことが目的になり、無駄でないテストまで落ちる。
5. 目指す状態だけを書き、文献の名前を書かない: 0094 は 35〜49 行と回ごとに割れる。
6. 目指す状態に「無駄なものが無く」を足す: 0094 は 35〜42 行で、足さないとき(31〜35 行)より残る。
7. 同値分割・境界値分析の行を、文献の名前で書いて残す: ISTQB CTFL を基準にすれば、行が無くても使われる。捨てた案4の行に足すと、0094 の「作る」が 13〜18 行から 15〜24 行に増えた。

## 理由

1. 利用者の理由: 出典の内容を、Claude がよく分からないまま言い換えるから、わけが分からなくなる。明確な出典があるなら、規則に書き直さなくてよい。用語集に、知られている IT の用語を載せないのと同じ。テストサイズ(ADR 0092-1)と同じ形にする。
2. 利用者の理由: テストは、減らすことが目的でなく、適正な量になってほしい。無駄なテストを削って最適化する。
3. 定石(ISTQB CTFL v4.0.1 5.2、https://www.istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf 。2026-11-24 に読んだ): プロダクトリスクのリスクレベルは、可能性と影響で決まる。リスク分析の結果で、テストの範囲・技法・量を決める。リスクへの対応には、テストによる軽減のほかに、受容がある。テストの量をリスクに合わせる文献なので、「適正な量」の基準になる。
4. 1冊にするのは、範囲(リスク)も値の選び方(同値分割・境界値分析)も ISTQB CTFL にあるから。Khorikov の本(1章、https://enterprisecraftsmanship.com/files/Unit-Testing-Chapter-1-Excerpt.pdf 。2026-11-24 に読んだ)は、値の選び方を決めていない。
5. 試し(2026-11-24。決まりの文書を読まない新しいセッションに、目指す状態の見出しと基準の行と、テストの名前の一覧を渡し、3回ずつ分けさせた): gemini の 0094 の 61 行は 35・31・31 行、gemini の標本 101 件は 44・37・33 件、LogiFee の会計の 34 行は 16・17・21 行、LogiFee の権限の 135 行は 75・69・76 行、LogiFee の API の標本 137 件は 72・46・66 件、画面の標本 103 件は 29・35・29 件。0094 で落ちた行の理由は、ほかの行が同じ決まりを確かめている・まれな入力で影響が小さい・データの写し・書き方の表示など。0094 の主な使い方と、LogiFee の源泉の逆算・仕訳・売掛金の残・立替の税区分は3回とも残った。ADR 0091-5 の行より残るテストは増える(0094 で 4〜5 行が 31〜35 行)ことを、利用者は見て決めた。
6. 文の読み(2026-11-24): 3つの新しいセッションが、基準の行を、リスクを可能性と影響で見積もり、リスクの高い所のテストを作って残し、リスクの低い所のテストは作らず、今あるものは消す、と読んだ。決まらないと答えた所は、版・線引き(シラバスも定めていない)・評価する人・今あるテストの範囲など。
7. small と medium だけでなく large にも当たる。large は、その上に、利用者の主な使い方1本につき1つまで(ADR 0005-1 の2)。
