# 0091-3 コードを変えるタスクの設計で、そのコードの要らないテストを消す

状態: 提案
日付: 2026-11-24
対象: task-team-test-list

## 決めたこと

設計のテスト一覧に、変えるコードに今あるテストのうち、残す基準に当たらないものを、消すテストとして書く。

## 捨てた案

1. 動きを変えた・消したときにだけ、それが前提のテストを消す(今のやり方。ADR 0040-1): 動きが変わらない限り、要らないテストは残り続ける。
2. 全部のテストを定期に見直すタスクを回す: 一度に読む量が多く、何を確かめたテストかを読み直すことになる(ADR 0040-1 の捨てた案3)。

## 理由

1. 定石: 価値が維持の手間を上回るテストだけを残し、ほかは消す(Khorikov 1章、https://enterprisecraftsmanship.com/files/Unit-Testing-Chapter-1-Excerpt.pdf)。
2. 変えるコードのテストは、その変更でどのみち読むので、消すかを決めるための読む量が増えない。
