# 0034-2 利用者の窓口は PL 1つにし、記録に無い前提の問いは SE の会話で受けて記録に書き足す

状態: 置き換え済み(0056-1)
日付: 2026-11-04
対象: task-team-lead・task-team-se

## 決めたこと

リポジトリで作業するとき、利用者が話しかける窓口は PL 1つにし、記録に無い前提まで聞く問いは PL がリンクを出す SE の会話で受け、分かった前提を SE が記録の「段階の前提」に書き足す。

## 捨てた案

1. 深い問いにも PL が答える: 会話が長くなって PL が古い部分を要約し、細部を落とす。そのあいだ、ほかのタスクの知らせも待たされる。
2. 窓口を決めず、利用者がタスクごとに子セッションと話す: 複数のタスクが混ざると、利用者はどこから何を把握すればよいか分からなくなる。
3. 分かった前提を SE の会話だけに残す: PL がその段階を聞かれたときに、記録から答えられない。

## 理由

1. 利用者は、あるリポジトリではそのセッションとだけ話していればよい形を望み、深い話が別の窓口に分かれることは受け入れた。
2. SE は設計を書いた本人で、段階の前提を一番よく知っている。記録に書き足せば、PL は記録だけで答えられる。
