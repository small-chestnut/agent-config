# 0102-1 かんばんのカードのデータを、ファイルから保存した行に移す

状態: 却下
日付: 2026-11-27
対象: team-kanban・team-kanban-page

## 決めたこと

かんばんのカードのデータを、アセットの JSON ファイル(`datasets/cards` の `kind: "file"`)のままにし、かんばんの保存先の保存した行(`kind: "store"`、カード1枚が1文書)には移さない。

## 捨てた案

1. 保存した行に移し、書き直しをそのカードの文書1つへの ArtifactData の書き込みだけにする: Artifact の道具でアセットを読めないセッション(gemini の PL のセッション)でも書き直せ、ほかの PL のカードを読まず、古いファイルも残らない。ただし、ページ・skill `team-kanban`・`team-kanban-page` を直し、今の 411 枚を1回だけ移すことになる。保存した行は、1つのデータで最初の 1000 文書までしか読まれない(Data 型の `artifact-type/reference/features.md` の「Saved rows」)。

## 理由

1. 失敗は、gemini の PL のセッション(2026-11-26 に始まった)の Artifact の道具にアセットを読む・上げるパラメータが無かったことによる。同じ頼む文で、2026-11-27 に始まったセッションのサブエージェントは書き直せた。
2. 利用者は、直し方の2つ(保存した行に移す・gemini の PL のセッションを始め直す)のうち、始め直すだけを選んだ。
3. 見直すのは、始め直したセッションでもアセットを扱えず、書き直せないとき。
