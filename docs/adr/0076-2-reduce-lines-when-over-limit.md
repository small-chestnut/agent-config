# 0076-2 全体の CLAUDE.md が上限を超えるときは、行を消すか skill に移して収め、収まらなければどの目的を先にするかを利用者に聞く

状態: 提案
日付: 2026-11-13
対象: 全体

## 決めたこと

全体の CLAUDE.md(`claude/CLAUDE.md`)が字数の上限(ADR 0076-1)を超えるときは、振る舞いを変えていない行と deny・フックが止めている操作の行を消し、次に特定の作業でだけ要る行をその作業の skill に移し、それでも収まらなければ、足す行と消す候補の行の目的を並べて、どちらを先にするかを利用者に聞く(詳しい文は `.claude/rules/global-claude-md.md`)。

## 捨てた案

1. 上限を上げる: 何字まで効きが薄まらないかを照らす根拠が無いまま、足すたびに量が増え続け、上限を置いた意味が無くなる。
2. 行をまとめる・言葉を詰めて字数を合わせる: 読まれる中身は減らず、行の数でしたのと同じ数合わせになる。詰めた文は、利用者にも一度読んで分からなくなる。
3. `@` の import で別のファイルに分ける: Claude Code は import したファイルも起動時に読むので、読まれる量は減らない(https://code.claude.com/docs/en/memory.md: 「helps organization but doesn't reduce context」)。
4. ユーザーの `~/.claude/rules/` に paths 付きのルールとして移す: 全体の CLAUDE.md の規則は、どのリポジトリのどのファイルでも効かせたいもので、paths で絞れる行が少ない。install スクリプトも `rules/` を配っていない。
5. 消す・移す行を、AI が決めずに毎回利用者に選ばせる: 利用者は手段の案を選ばされたくない。振る舞いを変えていない行・フックで止まる行・特定の作業でだけ要る行は、目的に照らして AI が決められる。

## 理由

1. 消すか移すかは、どちらも毎回読まれる量を本当に減らす。skill の本文は、呼ばれたときだけ読まれる(https://code.claude.com/docs/en/skills.md)。
2. 消す順を先にするのは、振る舞いを変えていない行は足しても効いていない行で(skill `prompt-structure` の「足しても振る舞いが変わらなかった規則は消す」)、deny・フックが止める操作は文に頼らずに守られている(`.claude/rules/global-claude-md.md` の安全の原則)から。
3. 消す・移す行が無いときに残るのは、どちらの目的を先にするかの選択で、目的を決めるのは利用者(全体の CLAUDE.md の「利用者に聞くのは、目的と「なぜ」だけ」)。
