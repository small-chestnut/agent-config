# 0035-5 利用者への説明は、利用者が目にするものから始め、AI の側の言葉を前提にしない

状態: 提案
日付: 2026-11-04
対象: 全体

## 決めたこと

利用者への説明は、利用者が実際に目にするもの(画面・答えの例・図)から始め、利用者がまだ見ていないものや、AI の側で使う言葉を前提にしない。

## 捨てた案

1. task-team の skill にだけ入れる: チームを使わない会話の説明は変わらず、同じ規則が PL・SE・PG の skill の3か所に分かれる。利用者は全部の会話を選んだ。
2. AI の側の言葉を、先に利用者に教えてから使う: 利用者が覚える語が増える。

## 理由

1. 利用者は、説明を何度聞いても分からず、読む気がなくなってきていると言った。目にしたものから始めれば、知らない語を拾わずに読める。
2. 全体の CLAUDE.md は PL・SE・PG のどの会話にも読み込まれるので、1か所で全部に効く。
