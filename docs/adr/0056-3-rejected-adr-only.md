# 0056-3 やらないと決まったタスクは、理由を却下の ADR に書き、それだけをマージする

状態: 採用
日付: 2026-11-10
対象: task-team-lead・task-team-se

## 決めたこと

壁打ちの結果やらないと決まったタスクは、SE が、見送った案と見送った根拠を状態「却下」の ADR に書き、PL が、チケットを消して、その ADR だけを既定のブランチにマージする。

## 捨てた案

1. 何も残さずにチームを閉じる: やらないと決めた理由が SE の会話にしか残らず、同じ話題がまた出たときに、前の判断を引けない。
2. チケットを消さずに残す: チケットは受け渡しの記録で、終わったら消す決まり(0022-2)。進み具合にも、終わったタスクが残り続ける。

## 理由

1. 採用しなかった決定を ADR に残すのは、広く使われているやり方。MADR のひな形は、状態に rejected を持つ(https://github.com/adr/madr/blob/develop/template/adr-template.md)。
2. チケットは終わると消えるので、既定のブランチに残る置き場が要る。ADR は、決定と理由を残す今の置き場。
