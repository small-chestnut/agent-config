# 0024-1 記録の置き場を、作業の結果を書く所の決まりと、それが指す手順の文書から読む

状態: 提案
日付: 2026-11-01
対象: task-team-lead・task-team-se・task-team-messaging

## 決めたこと

PL は、リポジトリの決まりのうち作業の結果をどこに書くかの決まりを、パスが無くても記録の置き場の決まりと読み、その決まりが指す手順の文書も読んで、記録の置き場と書き方を決める。

## 捨てた案

1. CLAUDE.md・rules・skills のどこにある決まりでも置き場として探す(4ea21e9 で入れ、e00a3b1 で取り下げた): ADR まで記録の置き場に書き出すおそれがある。
2. 直さず、タスクを始めるときに置き場と根拠を伝える行で、利用者が気づくのを待つ: 2026-11-01 の LogiFee で、利用者が「チケットではないの?」と聞くまで、PL は `docs/tasks` と言っていた。

## 理由

1. LogiFee の決まりは「チケットで任された作業は、チケットを読んで始め、結果をチケットに書いて終えている」でパスが無く、書き方は、その決まりが指す skill `ops-ticket` にだけある。
2. 読む範囲を、結果を書く所の決まりと、それが指す文書に限れば、ADR などほかの決定の置き場は動かない。利用者は、この形を選んだ。
