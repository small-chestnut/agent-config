# 0071-3 閉じる前のピン外しは手順に書かず、`archive_session` の返事で外す

状態: 採用
日付: 2026-11-12
対象: task-team-lead
置き換える: 0057-2 の、タスクを終えるときにピン留めを外してから閉じる手順

## 決めたこと

skill `task-team-lead` に閉じる前のピン外しの手順を書かず、PL は `archive_session` がピン留めを理由に閉じなかったときに、`set_pinned` で外してから閉じ直す。

## 捨てた案

1. 閉じる前にピン留めを外す手順の行を残す(今のやり方): ADR 0057-2 の理由4は、`archive_session` がピン留めしたセッションを閉じないことから、手順が要るとした。その道具は、閉じなかったことと理由を返すので(道具の説明)、行が無くても PL は外して閉じ直せる。行が残ると、プロンプトの肥大のもとになる。
2. 閉じる前にフックで外す: フックの `mcp_tool` がアプリの道具を呼べるかは、文書から確かめられない(ADR 0071-1 の捨てた案1)。
3. 外す手順を「子セッション3つを閉じる」行にまとめる: SKILL.md の決まりの行は 60 字までで、まとめると越える。

## 理由

1. `archive_session` は、ピン留めしたセッションを閉じず、そう返す(道具の説明)。閉じたまま放っておかれることも、ピン留めのまま閉じることも無い。
2. 増えるのは、タスクを終えるときの道具の呼び出しが1回だけ。
3. 利用者は、必ずする作業を道具の側に任せて、プロンプトの文量を浮かせることを選んだ。
