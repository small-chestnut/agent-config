# 0041-1 Edit・Write・MultiEdit が書く行を記録し、シェルのコマンドで足した行から除く

状態: 提案
日付: 2026-11-07
対象: check_rule_documents_changed_by_shell.py

## 決めたこと

`check_rule_documents_changed_by_shell.py` は、Edit・Write・MultiEdit がプロンプトを書く前に、その呼び出しで足す行を記録し、シェルのコマンドの後には、記録した行と同じ行を、そのコマンドで足した行から除く。

## 捨てた案

1. コマンドに名前が出るファイルだけを見る。
2. ほかのセッションが動いているリポジトリは見ない。
3. シェルのコマンドの後にも、そのコマンドで足した行を記録して、ほかのコマンドから除く。

## 理由

1. 2026-11-07 の誤った知らせは、PL のコマンドの間に、0038 の PG が Edit で書いた行だった。Edit の中身は書く前に分かるので、どの呼び出しの行かを言い切れる。Edit の行は、書いたときに字数の数えと問いを経ており、もう一度問わなくても見落としにならない。
2. 案1は、glob(`**/SKILL.md`)やスクリプトで書いた行を見落とす。案2は、PG と QA が同じ worktree で動くので、自分の書いた行まで見落とし、ほかのセッションが動いているかもフックからは分からない。
3. 案3は、2つのコマンドが重なると、先に終わった方が相手の行を自分の行として記録し、相手の本当の行を見落とさせる。シェルどうしが同じファイルに同じ時に書くことは稀なので、そのときは今のとおり両方が知らせる。
