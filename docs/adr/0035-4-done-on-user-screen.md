# 0035-4 画面のあるシステムでは、作業が済んだかを、AI が利用者の見るのと同じ画面を開いて確かめて決める

状態: 採用
日付: 2026-11-04
対象: task-team-se・task-team-messaging

## 決めたこと

画面のあるシステムでは、作業の済んだ印を利用者が見る画面に出るものにし、印を付ける子セッションは、利用者が見るのと同じ画面を開いて確かめてから済みにする。

## 捨てた案

1. プログラムが出す「処理しました」のような報告やテストの結果で済みにする: 処理が通ったという報告は、利用者の画面にどう出たかを示さない。
2. 毎回、利用者に画面を確かめてもらう: 利用者の手間が増え、確かめ待ちで作業が止まる。

## 理由

1. 済んだかは、依頼した人が動くものを見て決めるのが定石(https://blog.teamtreehouse.com/when-is-a-user-story-done-acceptance-criteria-definition-done?amp=1)。AI が利用者と同じ画面を見れば、利用者が見て決めるのに一番近い。
2. ADR 0011-3 で、画面が変わる変更は AI が画面のスクリーンショットを見て確かめると決めた。これを作業の済みの決め方にも当てる。
