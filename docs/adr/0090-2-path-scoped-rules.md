# 0090-2 特定のファイルを扱うときにしか要らない規則は、paths 付きの規則に置いて配る

状態: 採用
日付: 2026-11-17
対象: 全体

## 決めたこと

特定のファイルを扱うときにしか要らない規則は、全体の CLAUDE.md でなく `paths` 付きの規則(`claude/rules/<名前>.md`)に置き、install が各設定ディレクトリの `rules/` に配る。

## 捨てた案

1. skill に移す: skill は Claude が要ると判断したときだけ読まれ、読まれないことがある。`paths` 付きの規則は、合うファイルを読めば読み込まれる。
2. 仕様の置き場の行も移す: 仕様があることを知るのは、仕様のファイルを読む前。読んでから読み込まれる規則には置けない。
3. 用語集の行も移す: 残った行が2行で、見出しと `paths` を足すと字数が減らない。

## 理由

1. CLAUDE.md の1行1行は、関係のない作業でも毎回読まれる。特定のファイルでだけ要る行は `paths` 付きの規則に置くよう、公式の文書が勧めている(https://code.claude.com/docs/en/memory 。2026-11-17 に読んだ)。`~/.claude/rules/` の規則は、どのリポジトリにも効き、`paths` は作業しているフォルダから当てはめる。
2. 移したのは、テストのファイルを扱うときの行(テストサイズの決め方と印)と、CLAUDE.md・`docs/概要.md`・`.claude/verify-commands.txt` を扱うときの行(何を置くか・検証コマンドの書き方)。
3. 読み込まれるのは、合うファイルを読んだとき。全体の CLAUDE.md には、そのファイルを開くきっかけになる行(検証コマンドを CLAUDE.md に書き足す・テストサイズごとに実行する時)を残した。
4. この repo では、`.claude/rule-documents.txt` に `claude/rules/*.md` を書き、行の字数と文を確かめるフックの対象にした。
