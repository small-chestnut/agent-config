# 0090-1 ほかのリポジトリで読まれる文章は、消しても Claude の動きが変わらない文を消して少なく保つ

状態: 採用
日付: 2026-11-17
対象: 全体
置き換える: 0084-2 の、規則・仕様・コードを今の手段として読む2行を残す所・0035-5 の、まだ見ていないものと AI の側の言葉の2行・0038-1・0044-3・0063-1 の、名前が2つのときに揃える行と、手段を導けないときに聞く行・0068-1 の、探す先と、沿うとゴールが果たせないときに聞く行・0048-1 の2行・0045-2 の、読み始める順と skill `write-spec` を指す行・0084-3 の、読み直した文を照らす先の行・0004-1 の、全体の CLAUDE.md の ADR に残す決定の行(skill `task-team-adr` の目指す状態にある)

## 決めたこと

agent-config の2つ目の命題として、ほかのリポジトリで作業するときに読み込まれる文章(全体の CLAUDE.md・skill)は、消しても Claude の動きが変わらない文を消して少なく保つ(README)。

- 消すかどうかは、その文を消したとき、道具(Claude Code)の既定の指示・ほかの文・フック・deny で同じ動きになるかを、1文ずつ読んで決める。
- 消すと動きが変わる文でも、特定のファイルを扱うときにしか要らない文は、`paths` 付きの規則(`claude/rules/`)に移す。install が、各設定ディレクトリの `rules/` に配る。そのファイルを読んだときだけ読み込まれる。
- 全体の CLAUDE.md の冒頭に命題を置き、入れ子の一番上をそろえる。skill は全体の CLAUDE.md と一緒に読まれるので、skill ごとには置かない。
- 段は上の段が下の段を包含し、命題から目指す状態までは、子の段を全部果たすと親の段が果たせる(skill `prompt-structure`)。
- 原則の見出しは、名前のあとに、その原則を果たした姿の1文を置く。安全は「AI の操作で、利用者が取り返しのつかない損失を負わない」、人間側の最適化は「利用者が、AI の出力を、少ない負担で正確につかめる」、AI 側の最適化は「Claude が、どのリポジトリでも最善の性能を出せる」。全体の CLAUDE.md の安全の目的は、原則の文と同じになるので消す。
- 対象は、ほかのリポジトリで読まれる文章だけ。ADR・README・テストは、ほかのリポジトリでは読まれないので対象にしない。
- このタスクは、利用者の指示で task-team を通さず、PL のセッションで進めた。

## 捨てた案

1. ADR・README も含めて消す: 命題の理由は、ほかのリポジトリでの作業の負担。ADR は前の形と捨てた案を残す場所で(全体の CLAUDE.md)、ほかのリポジトリでは読まれない。
2. 場面でしか要らない文を skill に移す: skill は Claude が要ると判断したときだけ読まれ、読まれないことがある。`paths` 付きの規則は、合うファイルを読めば必ず読み込まれる。
3. 安全の節も同じ基準で消す: 行が無くて起きる損失は取り返しがつかない(ADR 0088-1 の捨てた案6)。安全の節から消したのは、deny とフックで機械的に止まる、push 済みのコミットを書き換える行だけにした。
4. 用語集の行を `paths` 付きの規則に移す: 移す行が1行で、目指す状態の見出しも写すと、字数が減らない。

## 理由

1. 利用者の理由: agent-config は、ほかのリポジトリで作業するときの拡張パーツで、そのリポジトリの決まりと一緒に読み込まれる。拡張パーツの文章が膨らむと、その分だけ負担になる。
2. ADR 0088-1 は、行の根拠を言えるかで消した。それを通った行でも、消すと動きが変わるかを問うと、全体の CLAUDE.md の規則の行 91 行のうち 28 行が消せた。公式の手引きも、各行について消すと Claude が間違えるかを問い、間違えないなら消すことを勧めている(https://code.claude.com/docs/en/best-practices 。2026-11-17 に読んだ)。
3. CLAUDE.md の1行1行は、関係のない作業でも毎回注意を取る。特定のファイルでだけ要る行は、`paths` 付きの規則に置くよう公式の文書が勧めている(https://code.claude.com/docs/en/memory 。2026-11-17 に読んだ)。
4. 原則の名前だけでは、その名前が何を指すかが分からず、命題とは原則である、と言えない(利用者の理由)。
5. 包含の2行は、利用者が「命題とは原則である」「原則とは目的である」と言えなければおかしいとしたことによる。入れ子で書くとだけ書くと、子の段を全部果たせば親が果たせることまでは読めなかった。
