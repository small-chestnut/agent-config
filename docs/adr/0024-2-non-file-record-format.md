# 0024-2 ファイルでない記録は、手順の文書が作業の結果を書く所に、ステータスの行で始めて書く

状態: 置き換え済み(0051-1)
日付: 2026-11-01
対象: task-team-lead・task-team-se・task-team-pg・task-team-qa

## 決めたこと

記録の置き場がファイルでなければ、SE・PG・QA は、記録の節を、置き場の手順の文書が作業の結果を書く所に書き、書き足す形なら1行目を「ステータス: 」にして書き足し、同じ節は新しいものを読む。図と画像は、手順の文書の添付の仕方で付け、無ければ `docs/tasks/<タスク名>/` に置いて、PL はそのフォルダを消さない。

## 捨てた案

1. 記録の節を、チケットの本文に書く: `ops-ticket` の本文は見出しが決まっていて、今の決まりだけを置く所。
2. SE・PG・QA の skill は変えず、PL が書き方を添えて渡す: PL が子セッションに渡す文は、記録の置き場と読む節と、タスクの文と、PL の答えだけに限っている。

## 理由

1. 2026-11-01 の LogiFee で PL は、ファイル前提の skill のまま、チケットの書き方をその場で組み立てて3つのセッションに送り直した。利用者は、子の skill も直す形を選んだ。
2. コメントのような書き足す形の置き場では、前に書いた節を書き換えられないことがあるので、新しいものを今の節とステータスにする。
3. ADR 0022-2 で消す記録と記録のフォルダは、ファイルの記録のもの。ファイルでない記録は残るので、そこから指す図のフォルダも残す。
