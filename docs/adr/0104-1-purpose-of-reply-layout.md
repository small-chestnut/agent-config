# 0104-1 返答の形(結論・補足・質問)の目的を、全体の CLAUDE.md の目的の段に書く

状態: 採用
日付: 2026-11-27
対象: 全体

## 決めたこと

全体の CLAUDE.md の人間側の最適化の原則に、目的「利用者が、返答の結論と、あれば質問だけを読めば、分かったことと、何を答えるかと、選ぶのに要ることをつかめる」を置き、結論・補足・質問の形を決める4行を、様態の公準の目的からその下へ移す。

## 捨てた案

1. 「質問は、…」の行を、次の一手の枠(wrap_up)に質問を出すときも本文に書く形に直す: 利用者は、質問が本文か枠かは本質ではなく、重ならなければ枠だけでよいとした。本文に質問を書いても、答えに要ることが補足にあれば、結論と質問だけでは答えられない。
2. 本文に質問が無いまま返答を終えるのを止めるフックを足す: 案1と同じく質問の置き場所を守らせるだけで、答えに要ることを補足に入れるのは止められない。
3. 答えに要ることを補足に入れない、という規則の行を足す: 目的から導けることなので、目的だけで守れるかを先に試す(skill `prompt-structure`)。

## 理由

1. 利用者の理由: 結論・水平線・補足・水平線・質問の形は、利用者が上の結論と、あれば下の質問だけを読めば済むための仕組み。
2. 今の4行は、並べる順番と水平線の場所だけを決め、この形の目的を書いていない。「補足」は、辞書では足りない所を補うもので、読まないと分からないとも読める。0103 の SE の返答には、水平線が1本も無いものと、答えに要る選択肢を補足に入れたものがあった(2026-11-27)。
3. 4行を目的の下に置くのは、目的を読めば、規則に無い場面でも、結論と質問だけで済むかで判断できるようにするため(ADR 0097-2)。様態の公準の目的の下には、ほかの3行が残る(ADR 0084-4)。
4. 見出しの文は、2026-11-27 に、決まりの文書を読まない `claude-opus-5-5` の新しいセッション3つに読ませ、3つとも同じ、意図どおりの意味に読んだ。実際の返答が変わるかは確かめていない。
