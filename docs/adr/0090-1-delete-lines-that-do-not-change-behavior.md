# 0090-1 ほかのリポジトリで読まれる文章は、消しても Claude の動きが変わらない文を消して少なく保つ

状態: 置き換え済み(0105-4)
日付: 2026-11-17
対象: 全体
置き換える: 0084-2 の、ADR 0046-3 の2行を残す所と、目的「利用者が、目的と「なぜ」を決めるだけで済む」を置く所・0088-1 の、安全の節を見直さない所

## 決めたこと

agent-config の2つ目の命題として、ほかのリポジトリで作業するときに読み込まれる文章(全体の CLAUDE.md・skill)は、消しても Claude の動きが変わらない文を消して少なく保つ(README)。

## 捨てた案

1. ADR・README も消す: 命題の理由は、ほかのリポジトリでの作業の負担。ADR と README は、ほかのリポジトリでは読まれない。
2. 消した行が元にした ADR を、置き換え済みにする: 消したのは、書かなくても同じ動きになると見た行で、ADR の決定は変えていない。変えた決定だけを「置き換える」に書いた。
3. 安全の節を、ほかの節と同じ基準で消す: 行が無くて起きる損失は取り返しがつかない(ADR 0088-1 の捨てた案6)。消したのは、deny とフックが止める1行(push 済みのコミットを書き換える)と、原則の文と同じになった目的の見出しだけ。
4. 分けた skill を名前で指す行を消す: skill の説明だけに任せると、呼ばれないことがある(ADR 0089-1 の捨てた案3)。全体の CLAUDE.md の skill `write-spec` を指す行は、一度消して戻した。
5. task-team で進める: 利用者は、消せる基準をいちばん持っているのが壁打ちをした PL の会話だとして、この会話で進めると決めた。

## 理由

1. 利用者の理由: agent-config は、ほかのリポジトリで作業するときの拡張パーツで、そのリポジトリの決まりと一緒に読み込まれる。拡張パーツの文章が膨らむと、その分だけ負担になる。
2. 消すかどうかは、その文が無くても、道具(Claude Code)の既定の指示・上の段の見出し・ほかの行・テンプレートや既にある文書・フックと deny で同じ動きになるかを、1文ずつ読んで決めた。公式の手引きも、Claude がコードから分かることを CLAUDE.md に書かないよう勧めている(https://code.claude.com/docs/en/best-practices 。2026-11-17 に読んだ)。
3. ADR 0088-1 は、行の根拠を言えるかで消した。それを通った行でも、消すと動きが変わるかを問うと、全体の CLAUDE.md の規則の行 91 行のうち 30 行ほどが消せた。
4. 形や順だけを決めていて ADR の付いていない行(操作を頼む文の順・依存の渡し方など)は、決まりごと無くした。目指す状態を満たす形は、その場で選べる。
5. 目的「利用者が、目的と「なぜ」を決めるだけで済む」の段は、利用者が要らないとした。「なぜ」は要るが、やり方は AI が勧めたものに決まることがほとんどで、道具の既定の指示も、聞くのは利用者が決めることだけにしている。「なぜ」を残す決まりは、別の目指す状態にある。
6. 消しすぎは、AI が状態を守れなかった所で気づいて、git の履歴から戻せる(ADR 0088-1 の理由6)。
