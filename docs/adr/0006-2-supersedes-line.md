# 0006-2 新しい ADR に「置き換える: 」の行を書き、置き換えた古い ADR へたどる

状態: 採用
日付: 2026-10-31
対象: task-team-se

## 決めたこと

決定を置き換える新しい ADR は、冒頭の「対象: 」の次に「置き換える: <古い ADR の番号>」の行を書き、古い ADR の状態は今のとおり「置き換え済み(<新しい番号>)」にする。

## 捨てた案

1. 新しい ADR には何も書かず、`docs/adr/` を「置き換え済み(<新しい番号>)」で検索して古い ADR を探す。

## 理由

1. 両方向に書くのが定石: adr-tools は、新しい ADR に「Supercedes」、古い ADR に「Superceded by」を書く(https://github.com/npryce/adr-tools/blob/master/tests/supercede-existing-adr.expected)。
2. 新しい ADR を読めば古い ADR の番号が分かり、検索の手間が要らない。
3. 決定をいくつも持つ 0004-1・0005-1 の一部だけを置き換えるときは、「置き換える: <番号> の<決めたことの番号>」と書き、残りの決定が効いているので古い方の状態は変えない。
