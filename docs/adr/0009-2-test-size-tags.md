# 0009-2 テストの大きさは、中と大にだけテストの道具のタグで印を付け、印の無いテストを小とする

状態: 提案
日付: 2026-10-31
対象: 全体

## 決めたこと

リポジトリに決まりが無ければ、中と大のテストにテストの道具のタグ(マーカー・カテゴリ)で `medium`・`large` を付け、タグの無い道具ではファイル名に `.medium`・`.large` を入れ、印の無いテストを小とする。

## 捨てた案

1. 大きさごとにフォルダを分ける(`tests/small/` など)。
2. 小・中・大のすべてに印を付ける。
3. 印を付けず、流すときに大きさを判断する。

## 理由

1. 書いている間は小だけを、マージ前は小と中を流すので、大きさを選んで流せる印が要る(ADR 0009-3)。案3では、流すたびに中身を読むことになる。
2. 印をテストの中に書くのは、Google がテストごとに大きさの属性を書く(Bazel の `size`、https://bazel.build/reference/test-encyclopedia)のと同じ形。grep で見つかる。案1は、テストを確かめる対象のモジュールのフォルダに置く決まり(skill `module-layout`)とぶつかる。
3. ほとんどのテストは小なので、中と大にだけ付ければ印を書く手間が少ない(案2)。
