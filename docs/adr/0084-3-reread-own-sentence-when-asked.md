# 0084-3 自分の文の意味を問われるか食い違いを指摘されたら、説明を始める前にその文を読み直し、辞書・用語集・同じ答えの中の使い方と照らす

状態: 提案
日付: 2026-11-14
対象: 全体
置き換える: 0074-1

## 決めたこと

全体の CLAUDE.md に、自分の文の意味を問われるか食い違いを指摘されたら、説明を始める前にその文を読み直し、辞書・用語集・同じ答えの中の使い方と照らす規則だけを置く(ADR 0074-1 の3行のうち、一般の語を辞書と違う意味で説明しかけたら誤用を疑う行と、誤りに気づいたら認めてから言い直す行は消す。詳しい文は全体の CLAUDE.md)。

## 捨てた案

1. ADR 0074-1 の3行をそのまま残す: 3行とも、利用者には曖昧で理解しがたい。下の理由のとおり、2行は働かず、1行は何をするかが一意に決まらない。
2. 3行とも消す: 意味を問われたこと・食い違いを指摘されたことは、外から分かる出来事なので、その時に読み直す手順は毎回踏める。0084 の SE も、表の文の意味を問われて読み直し、後半を落としていた誤りに気づいた。

## 理由

1. 利用者の理由: 大事なのは誤りに気づけるかで、誤りと自覚すれば訂正は必ずする。誤りに気づいた後の行は要らない。
2. 一般の語を辞書と違う意味で説明しかけたら誤用を疑う行は、違う意味だと気づけることを前提にしていて、気づけないときに働かない。
3. 「誤りを疑う」は心の動きの言葉で、何をするかが一意に決まらない。この行でできることは、説明を始める前に前の文を読み直し、辞書・用語集・同じ答えの中の使い方と照らすこと(照らす相手は ADR 0074-1 の理由1・2 で食い違いが見つかった所)。
