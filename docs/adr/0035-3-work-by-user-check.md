# 0035-3 作業は、利用者が確かめる単位で切り、利用者が確かめる順に並べる

状態: 採用
日付: 2026-11-04
対象: task-team-se

## 決めたこと

SE は、タスクの作業を、利用者が確かめる単位(データの種類など)で切り、利用者が確かめる順に番号を振る。

## 捨てた案

1. AI が作りやすい単位(ファイル・処理の順)で切る: 作業が済んでも、利用者は何を確かめればよいか分からず、説明を聞き直すことになる。
2. 済んだ印1つで確かめられる大きさに切るだけにする(0034-1 の形): 大きさは揃うが、利用者が見る単位とずれる。

## 理由

1. 利用者は、人間が把握できる順で作業してほしいと決めた。作業の済みは利用者に説明するので、作業の単位と説明の単位が同じなら、説明が1つで済む。
2. ユーザーストーリーは依頼した人が確かめられる単位で切り、済んだかを受け入れ条件で決めるのが定石(https://blog.teamtreehouse.com/when-is-a-user-story-done-acceptance-criteria-definition-done?amp=1)。
