# 0105-4 このリポジトリの命題を、読み込まれる文章が、あるべきものを、あるべき量だけ持つことにし、正否と要不要の原則を導く

状態: 提案
日付: 2026-11-28
対象: 全体
置き換える: 0090-1

## 決めたこと

agent-config の命題(このリポジトリ)を、ほかのリポジトリで作業するときに読み込まれる文章(全体の CLAUDE.md・skill)が、あるべきものを、あるべき量だけ持つことにし、そこから、正否(IT のベストプラクティスに沿う)と要不要(無くても Claude ができることを持たない)の原則を導く(リポジトリ直下の CLAUDE.md の冒頭)。

## 捨てた案

1. 今の命題(消しても Claude の動きが変わらない文を消して、少なく保つ)のままにする: 命題には要不要の軸しか無い。タスク 0105 では、安全の節の行を、消しても動きが変わらないかだけで照らし、残った行が正しいかを照らさなかった。
2. 正否の軸を、skill `prompt-structure` の規則の1行にする: 要不要が命題にあるので、正否も同じ重さで、規則の段では軽すぎる(利用者の理由)。skill は、ほかのリポジトリでも読まれ、その分だけ量が増える。
3. 命題に「IT のベストプラクティスに沿わせ、消しても Claude の動きが変わらない文を消して、少なく保つ」と2つの軸を並べて書く: 「少なく保つ」は、量を減らすことが目指すものになり、あるべき文まで消す向きに働く(利用者の理由)。
4. 原則を見出し(`# 原則`)にする: リポジトリ直下の CLAUDE.md は、命題の後に規則の行を並べている。見出しにすると、その下の規則の行がみなその原則の下に入る。

## 理由

1. 利用者の理由: ルールの要不要と正否は別の軸で、要不要は、無くても Claude ができるものを消し、正否は、IT のベストプラクティスに沿わせる。元からそれを意図していたが、伝わらなかった。本質は、あるべきものを、あるべき量もつこと(2026-11-28)。
2. 2つの軸は、別の種類の要らない行を見つける。正否は、動きが変わっても直すか消すべき行(外れた行)を、要不要は、動きが変わらない行(書かなくても同じになる行)を見つける。消すと動きが変わるかだけでは、正しくない行が残る。
3. どちらの軸でも決まらない行は、そのリポジトリか利用者に固有のことで、無くても Claude ができることに当たらないので、要不要の原則のとおり持つ。
4. ADR 0090-1 の理由(拡張パーツの文章が膨らむと、ほかのリポジトリでの作業の負担になる・消すかは、道具の既定の指示・上の段・ほかの行・フックと deny で同じ動きになるかで決める)は、要不要の原則の理由として変わらない。
