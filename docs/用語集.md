# 用語集

このリポジトリには画面が無いので、「コードの名前」には、ファイル名と、記録・ADR に書く字を書く。

| 業務の言葉 | コードの名前 | 画面に出す字 | 意味 |
|---|---|---|---|
| タスクの番号 | `<番号>`(例: `0004`) | — | タスクごとの4桁の連番 |
| タスク名 | `<タスク名>`(例: `0004-adr-driven`) | — | タスクを指す名前 |
| ADR | `docs/adr/<ADR の番号>-<英語の短い題>.md` | — | 後から変えにくい決定の記録 |
| ADR の番号 | `<タスクの番号>-<そのタスクの中の連番>`(例: `0004-1`) | — | ADR を書いたタスクと、そのタスクの中の順 |
| ADR の状態 | `状態: 提案`・`採用`・`却下`・`廃止`・`置き換え済み(<ADR の番号>)` | — | その決定がいま効いているか |
| 仕様 | `docs/specs/<モジュール>.md` | — | モジュールの今の、外から見える動き |
| 仕様の「ADR」の節 | 仕様の `## ADR` | — | そのモジュールに効く ADR の、番号と題の並び |
| 機能の節 | 仕様の `## <機能の名前>` | — | 機能1つの業務の規則を並べた節 |
| 次に回すタスク | — | `次に回すタスク` | 利用者に聞かずにタスクにし、まだチームを起こしていないタスク |
| 命題 | — | — | リポジトリの目的(システムを作る理由) |
| 壁打ち | — | — | タスクにする前に、利用者と PL が依頼について話すこと |
| タスクの文 | — | — | タスクにした利用者の依頼の文 |
| PL の答え | — | — | タスクの文が受けている PL の返答 |
| 記録 | `docs/tasks/<タスク名>.md`、またはリポジトリの決まりの置き場(チケットなど) | — | SE・PG・QA がタスクを受け渡すための、ゴールからレビューまでの節 |
| 記録の置き場 | ファイルなら記録のパス。ファイルでなければ番号(チケットの番号など)と、置き場の手順の文書のパス | — | 記録がどこにあり、どう書くか |
| 置き場の手順の文書 | — | — | 作業の結果を書く所の決まりが指す、書き方の文書(skill など) |
| テスト一覧 | 記録の設計の節の `## テスト一覧` の表 | — | 作るテストの名前・大きさ・受け入れ条件の表 |
| テストの大きさ | 小・中・大 | — | テストが使う資源の範囲 |
| テストの基準 | `task-team-se` の、テスト一覧の2つの目指す状態 | — | 作るテストと作らないテストと、大きさの決め方 |
| モジュール | 規則の中では `modules/<モジュール>/`。このリポジトリでは skill の名前か hooks のファイル名 | — | 業務のまとまり |
| 公開の入口 | モジュール直下の1つのファイル(`index.ts`・`__init__.py`・`<モジュール>Api`) | — | ほかのモジュールが使ってよいものだけを出すファイル |
| パス指定のルール | `.claude/rules/<名前>.md`(冒頭の `paths`) | — | `paths` に当たるファイルを Claude が読むか書いたときだけ読み込まれる決まりの文書。agent-config では、skill のフォルダの外にある `claude/` のファイルの「なぜ」を置く |
| リポジトリの決まり | — | — | 作業するリポジトリにコミットされた文書に書かれた決まりと、既にあるファイルの並び |
| 確かめのコマンド | `.claude/verify-commands.txt` の1行(コマンドの頭) | — | テストや lint のコマンドの頭 |
| 確かめのコマンドの一覧 | `.claude/verify-commands.txt` | — | リポジトリごとの、確かめのコマンドの頭の一覧 |
| 中身の印 | `docs/` を除いた作業ツリーの git の tree の id | — | 作業ツリーの中身を表す印 |
| ターンの始めの印 | 確かめの記録の `turn_start` | — | セッションごとの、ターンの始めの中身の印 |
| 確かめの記録 | `<git の共通のフォルダ>/claude-verify.json`・`require_verify_before_stop.py` | — | ターンの始めの印と、中身の印ごとに通った確かめのコマンドの記録 |
| 結論 | 返答の1行目 | — | 返答で一番言いたいこと |
| 補足 | 返答の1本目の水平線の下の文(400 字まで) | — | 結論を支える説明 |
