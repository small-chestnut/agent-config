# 用語集

| 用語 | 意味 |
|---|---|
| 次に回すタスク | 利用者に聞かずにタスクにし、まだチームを起こしていないタスク |
| 命題 | リポジトリの目的(システムを作る理由) |
| タスクの文 | タスクにした利用者の依頼の文 |
| PL の答え | タスクの文が受けている PL の返答 |
| 記録 | SE・PG・QA がタスクを受け渡すための、ゴールからレビューまでの節 |
| 記録の置き場 | 記録がどこにあり、どう書くか |
| 置き場の手順の文書 | 作業の結果を書く所の決まりが指す、書き方の文書(skill など) |
| テストの基準 | 作るテストと作らないテストと、大きさの決め方 |
| モジュール | 業務のまとまり。このリポジトリでは skill 1つか hooks のファイル1つ |
| リポジトリの決まり | 作業するリポジトリにコミットされた文書に書かれた決まりと、既にあるファイルの並び |
| 確かめのコマンド | テストや lint のコマンドの頭 |
| 中身の印 | `docs/` を除いた作業ツリーの中身を表す印 |
| ターンの始めの印 | セッションごとの、ターンの始めの中身の印 |
| 確かめの記録 | ターンの始めの印と、中身の印ごとに通った確かめのコマンドの記録 |
| 取り込むコマンド | git の merge・pull など、ほかのコミットの中身を作業ツリーに持ってくるコマンド |
| 進み具合 | 利用者待ちの行と、作業の一覧を並べた、記録の節 |
| 作業 | 利用者が確かめる単位で切った、タスクのひと区切り。進み具合の図の箱1つ |
| 前 | 先に済んでいなければならない作業の番号。進み具合の図の矢印 |
| 作業の印 | 作業のまだ・作業中・済み。進み具合の図の箱の色 |
| 済んだ印 | 作業が済んだと決める、確かめられる事実 |
| 利用者待ち | 子セッションが利用者を待っていることと、その会話へのリンク。待つものが無ければ「なし」 |
| 作業の前提 | 利用者が SE の会話で聞いて分かった、作業の拠り所 |
| 進み具合の図 | 進み具合から描く、作業を箱・前を矢印・作業の印を色にした図 |
