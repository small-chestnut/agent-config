# ask_about_written_lines.py

## ADR

- 0055-1 自動メモリにも、プロンプトの字数の数えと問いを掛ける
- 0055-2 例の並びの問いを、消せる語の問いと同じ知らせに入れる
- 0061-1 プロンプトの段は、命題を頂点に、すぐ上の段から導いて書く
- 0090-5 決まりの1行を 60 字までにする上限をやめる
- 0095-1 プロンプトの段は、目指す状態を無くし、命題・原則・目的・規則の4段にする

## 足した行を問い返す

- プロンプトを保存すると、HEAD から足した行のうち、この保存で書いた文字列を含む行だけを、行番号付きで並べて Claude に返す。
- この保存で書いた文字列が行の一部でも、その行を問う。
- HEAD から変わっていない行は、この保存で書いた文字列を含んでいても問わない。
- 空の行とコードブロックの中の行は問わない。
- この保存で書いた文字列は、Edit では new_string、MultiEdit では各編集の new_string、Write では content。
- 問いは、消しても意味が変わらない語と、決まりや事実を1文で言わずに具体例や出来事を並べている所の2つ。
- 問う行に原則・目的の見出しがあれば、すぐ上の段から導いた文にし、下の段の手段の言葉を入れないことも問う。
- 自動メモリでは、HEAD から足した行の代わりに、「自動メモリ」の節の足した行を使う。

## プロンプト

- 名前が CLAUDE.md・AGENTS.md・SKILL.md のファイルは、プロンプト。
- `.claude/rule-documents.txt` に書いた glob に当たるファイルもプロンプト。その一覧の空の行と `#` で始まる行は読まない。
- git にまだ入っていないプロンプトは、全部の行を足した行とする。
- UTF-8 でないプロンプトも、落ちずに読む。
- 自動メモリのほかの、git の外のファイルは問わない。
- プロンプトと自動メモリを見分け、足した行を取る処理は、`rule_document_added_lines.py` にある。

## 自動メモリ

- 設定ディレクトリ(`CLAUDE_CONFIG_DIR`、無ければ `~/.claude`)の `projects/<プロジェクト>/memory/` の下の md は、自動メモリ。
- 自動メモリでは、Write は全部の行を、Edit と MultiEdit は `new_string` が掛かる行のうち `old_string` に無い行を、足した行とする。
- 自動メモリの Edit で、書いた所が1つに決まらないときは、`new_string` が現れる所をみな足した行とする。
