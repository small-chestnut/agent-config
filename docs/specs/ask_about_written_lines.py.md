# ask_about_written_lines.py

## ADR

- 0055-1 自動メモリにも、プロンプトの字数の数えと問いを掛ける
- 0055-2 例の並びの問いを、消せる語の問いと同じ知らせに入れる
- 0061-1 プロンプトの段は、命題を頂点に、すぐ上の段から導いて書く

## 足した行を問い返す

- プロンプトの決め方と、HEAD から足した行の取り方は、check_rule_length.py と同じ。
- プロンプトを保存すると、HEAD から足した行のうち、この保存で書いた文字列を含む行だけを、行番号付きで並べて Claude に返す。
- この保存で書いた文字列が行の一部でも、その行を問う。
- HEAD から変わっていない行は、この保存で書いた文字列を含んでいても問わない。
- 空の行とコードブロックの中の行は問わない。
- この保存で書いた文字列は、Edit では new_string、MultiEdit では各編集の new_string、Write では content。
- 問いは、消しても意味が変わらない語と、決まりや事実を1文で言わずに具体例や出来事を並べている所の2つ。
- 問う行に原則・目的・目指す状態の見出しがあれば、すぐ上の段から導いた文にし、下の段の手段の言葉を入れないことも問う。
- 自動メモリでは、HEAD から足した行の代わりに、`check_rule_length.py` と同じ決め方の足した行を使う。
