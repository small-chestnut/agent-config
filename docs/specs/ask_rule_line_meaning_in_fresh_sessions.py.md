# ask_rule_line_meaning_in_fresh_sessions.py

## ADR

- 0087-1 規則の1行は、決まりの文書を読まない3つのセッションにスクリプトで読ませ、答えが同じ意味で意図と合うまで直す

## 動き

- スクリプトは、引数で渡した規則の1行を3つのセッションに同時に読ませ、3つの答えを「## 答え1」〜「## 答え3」の見出しの下に並べて出す。
- セッションは、`claude -p` で、セッションごとに新しく作った空のフォルダから起動する。
- セッションは、環境変数 `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` を付けて起動し、どの CLAUDE.md も読まない。
- スクリプトは、サインイン情報を写さず、環境変数 `HOME`・`USERPROFILE` を変えない。
- セッションは、`--setting-sources ""`・`--disable-slash-commands`・`--tools ""`・`--no-session-persistence` を付けて起動し、設定・skill・道具を使わず、記録を残さない。
- 読ませる文は、引数でなく標準入力に UTF-8 で渡し、渡し終えたら標準入力を閉じる。
- 読ませる文は、決まった4つの問い(何をする決まりか・守っている例・破っている例・意味が1つに決まらない所)と、渡した規則の1行だけ。
- モデルは、`--model` で指定しなければ `claude-opus-5-5`。
- 3つのセッションのどれかが 0 でない終了コードで終わったら、そのセッションの出力を添えて、終了コード 1 で終わる。
- `claude` のコマンドが見つからなければ、そう出して、終了コード 1 で終わる。
- 作った空のフォルダは、終わったら消す。
