# require_verify_before_stop.py

## ADR

- 0011-1 終わる前の確かめは、Claude が自分で走らせた確かめのコマンドが今の中身で通ったかを、Stop フックが見て守らせる
- 0011-2 確かめのコマンドの頭は、各リポジトリの `.claude/verify-commands.txt` に1行ずつ書く

## ターンの終わりに止める

- Stop フックは、ターンの始めから中身が変わり、今の中身で通っていない確かめのコマンドがあれば、その頭を並べてターンを止める。
- Stop フックは、今の中身で一覧の確かめが全部通っていれば止めない。
- Stop フックは、ターンの始めの印が無いか、ターンの始めから中身が変わっていなければ止めない。

## 確かめを数える

- 確かめのコマンドの一覧は、空の行と `#` で始まる行を読まない。
- 確かめのコマンドの頭と同じか、頭と空白で始まるコマンドが Bash か PowerShell で通ると、今の中身でその確かめが通ったと記録される。
- パイプ・`;`・`&`・改行を含むコマンドと、バックグラウンドで走らせたコマンドは、確かめとして数えない(`2>&1` は数える)。

## 中身の印

- 中身の印は、コミットしても、`docs/` の下だけを変えても変わらない。
- 中身の印は、まだ追っていないファイルを足すと変わる。
- 中身の印は、ファイルを前に書いたのと同じ秒の中に、同じ大きさで書き換えても変わる。

## 確かめの記録

- 確かめの記録を、いくつものフックが同時に書いても、ターンの始めの印と通った確かめは消えない。
- 確かめの記録が読めないか壊れていれば、フックは落ちずに空として扱う。

## 何もしないとき

- 確かめのコマンドの一覧が無いリポジトリと、git の外では、フックは何もしない。
