# require_verify_before_stop.py

## ADR

- 0011-1 終わる前の確かめは、Claude が自分で走らせた確かめのコマンドが今の中身で通ったかを、Stop フックが見て守らせる
- 0011-2 確かめのコマンドの頭は、各リポジトリの `.claude/verify-commands.txt` に1行ずつ書く

## ターンの終わりに止める

- Stop フックは、ターン開始時から作業ツリーのハッシュ値が変わり、今の作業ツリーで通っていない検証コマンドがあれば、それを並べてターンを止める。
- Stop フックは、今の作業ツリーで一覧の検証コマンドが全部通っていれば止めない。
- Stop フックは、ターン開始時の作業ツリーのハッシュ値が無いか、ターン開始時から作業ツリーのハッシュ値が変わっていなければ止めない。

## 検証を数える

- 検証コマンドの一覧は、空行と `#` で始まる行を読まない。
- 一覧の行をプレフィックスとして、それと同じか、それと空白で始まるコマンドが Bash か PowerShell で通ると、今の作業ツリーでその検証コマンドが通ったと記録される。
- パイプ・`;`・`&`・改行を含むコマンドと、バックグラウンドで走らせたコマンドは、検証として数えない(`2>&1` は数える)。

## 作業ツリーのハッシュ値

- 作業ツリーのハッシュ値は、コミットしても、`docs/` の下だけを変えても変わらない。
- 作業ツリーのハッシュ値は、未追跡のファイルを足すと変わる。
- 作業ツリーのハッシュ値は、ファイルを前に書いたのと同じ秒の中に、同じファイルサイズで書き換えても変わる。

## 検証の状態ファイル

- 検証の状態ファイルを、いくつものフックが同時に書いても、ターン開始時の作業ツリーのハッシュ値と通った検証コマンドは消えない。
- 検証の状態ファイルが読めないか壊れていれば、フックは落ちずに空として扱う。

## 何もしないとき

- 検証コマンドの一覧が無いリポジトリと、git の外では、フックは何もしない。
