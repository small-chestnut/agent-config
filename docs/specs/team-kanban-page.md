# かんばんのページ

## ADR

- 0056-4 全部のタスクの進み具合は、利用者のアカウントに1枚あるかんばんで見せる

## 動き

- カードのデータの1行を、カード1枚にして出す。
- リポジトリごとにタブを出し、選んだリポジトリのカードだけを出す。
- 開いたときは、リンクの `#` の後のリポジトリを選ぶ。無ければ、データの最初のリポジトリを選ぶ。
- カードは、ステータスで決まる列(まだ・壁打ち・設計・実装・見直し)に出す。
- 「壁打ち中」は壁打ち、「設計」で始まるものは設計、「実装レビュー」で始まるものは見直しの列に出す。
- 「実装」か「利用者の操作待ち」で始まるものは、実装の列に出す。ほかは、まだの列に出す。
- まだの列のカードには、ステータスを出す。
- サブタスクの全部の数があるカードには、済みの数と全部の数を、棒と数字で出す。
- 利用者待ちの文があるカードには「あなた待ち」の印を出し、その文をかんばんの上にも出す。
- タブには、そのリポジトリの、利用者待ちのカードの数を出す。0 なら出さない。
- かんばんの上に、全部のリポジトリの、まだの列にないカードの数と、利用者待ちのカードの数を出す。
- カードには、チームのいる PC を出す。無ければ出さない。
- データが0行なら、タスクが無いことを出す。
- 幅が狭いときは、列を縦に並べる。
