# push_after_ticket_commit.py

## ADR

- 0071-1 道具を使った直後に例外なくする作業は、プロンプトに書かずにフックに任せる
- 0056-5 チケットの今はほかの PC からも見える

## 動き

- Bash・PowerShell で `git commit` を走らせた後に動く。ほかの道具と、`git commit` を含まないコマンドの後には、何もしない。
- HEAD を見る作業ツリーは、`git -C <パス> commit` なら <パス>。無ければ、`git commit` より前の最後の `cd <パス>`・`Set-Location <パス>` の <パス>。どちらも無ければ入力の cwd。相対パスは入力の cwd から読み、パスを囲む引用符は外す。
- チケットは、HEAD のコミットで足した・直した・消した .md のうち、HEAD かその親での冒頭5行に「ステータス: 」で始まる行があるもの。
- チケットに触れないコミット・リモートの無いリポジトリ・ブランチに居ない HEAD の後には、push しない。
- リモートは origin。無ければ `git remote` の1行目。
- 上流があれば `git push`、無ければ `git push -u <リモート> HEAD` で push する。
- push したら「チケットのコミットを <リモート>/<ブランチ> へ push した。」を、失敗したら「チケットのコミットの push に失敗した:」と git の出力を、Claude に知らせる。
