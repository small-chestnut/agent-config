# check_rule_length.py

## ADR

- なし

## 字数を知らせる

- プロンプトを保存して、HEAD から足した決まりの行に 60 字を超える行があれば、その行番号を並べて Claude に返す。
- HEAD からある決まりの行は、60 字を超えていても知らせない。
- git にまだ入っていないプロンプトは、全部の決まりの行を数える。
- UTF-8 でないプロンプトも、落ちずに数える。

## 字数の数え方

- 決まりの行は、行頭の空白の後に「- 」が続く行で、コードブロックの中の行は除く。
- 字数は「- 」より後ろを数え、60 字までは知らせず、61 字から知らせる。
- `…` で囲んだコードは1字と数える。

## プロンプト

- 名前が CLAUDE.md・AGENTS.md・SKILL.md のファイルは、プロンプト。
- `.claude/rule-documents.txt` に書いた glob に当たるファイルもプロンプト。その一覧の空の行と `#` で始まる行は読まない。
- git の外のファイルは数えない。
