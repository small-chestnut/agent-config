# check_rule_documents_changed_by_shell.py

## ADR

- 0041-1 Edit・Write・MultiEdit が書けた行を記録し、シェルのコマンドで足した行から除く

## 見るリポジトリ

- フックは、cwd と、コマンドに書かれた絶対パス(`C:/…`・`C:\…`・`/c/…`・`~/…`)が入っている git リポジトリを見る。
- 見るリポジトリは、8つまで。
- git の外では、フックは何もしない。

## 足した行

- プロンプトは、`check_rule_length.py` と同じ決め方で、git が無視するファイルを除く。
- コマンドの前のスナップショットと比べて、足した行と書き換えた行を、このコマンドで足した行とする。消しただけの行は数えない。
- コマンドの前から作業ツリーにあった変更は、足した行に数えない。
- コマンドで作ったプロンプトは、全部の行を足した行とする。
- Edit・Write・MultiEdit がそのファイルに書いた行と同じ行は、足した行に数えない。

## 取り込んだ行

- フックは、git の merge・pull・checkout・switch・rebase・cherry-pick・reset・restore・revert・am を走らせたコマンドを、取り込む git コマンドとする。
- 取り込む git コマンドでは、コマンドの後の HEAD かインデックスの中身と同じ行を、足した行に数えない。
- 取り込む git コマンドでは、git が書いたコンフリクトマーカーの行も、足した行に数えない。
- 取り込む git コマンドでも、HEAD ともインデックスとも違う行は、足した行に数える。
- 取り込む git コマンド以外では、コミットした行も足した行に数える。

## 知らせる

- 足した決まりの行が上限の 60 字を超えると、ファイル・行番号・字数・本文を並べ、短くするよう知らせる。
- 足した行を、空の行とコードブロックの中を除いて並べ、消しても意味が変わらない語を探すよう問う。
- 知らせか問いがあれば exit 2 で Claude に返し、無ければ exit 0。

## 何もしないとき

- コマンドの前のスナップショットが無ければ、フックは何もしない。
- スナップショットを取るのに失敗しても、コマンドは止めない。
- Edit・Write・MultiEdit では、フックは知らせず、書き込みを止めない。
