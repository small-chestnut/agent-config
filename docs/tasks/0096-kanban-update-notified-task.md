## ゴール

1つのタスクのことで PL が動いたとき、そのタスクのカードだけを書き直す。

範囲外: かんばんのページの見た目と、カードの項目。利用者に進み具合を聞かれたときの、リポジトリの全部のカードの書き直し(今のまま残す)。

## 要件

### R1 知らせの来たタスクのカードだけを動かす

- 要件: チーム A から知らせが来たら A のカードを動かし、チーム B から知らせが来たら B のカードを動かす。知らせの来ていないタスクは見直さない。PL がタスクを始めた・終えた・まだ始めていないチケットを作ったときも、そのタスクのカードだけを動かす。
- なぜ: 知らせの来たタスクのカードだけを動かすのが自然で、ほかのタスクは知らせが来た時に動かせば足りる。
- 受け入れ条件 R1-1: チケットの保存先を1つ渡されたサブエージェントが読むチケットは、渡されたものだけ。
- 受け入れ条件 R1-2: R1-1 の書き直しの前後で、かんばんのデータの、渡したタスクのほかの行は、どの項目も変わらない。
- 受け入れ条件 R1-3: 無いチケットの保存先を渡された書き直しの後、かんばんのデータにそのタスクの行が無く、ほかの行はどの項目も変わらない。
- 受け入れ条件 R1-4: `claude/skills/task-team-lead/SKILL.md` と `claude/skills/team-kanban/SKILL.md` の行が、設計の「置くファイルと名前・データ」の直した後の行と同じ。

### サブタスクの前提

- かんばんの手順には、全部のカードを作り直す理由が無い。最初の形(e0c02cd)は「ほかの PL のカードを消さない」ために自分のリポジトリのカードに絞っただけで、ADR 0056-4・0058-1 とチケット 0056・0058 にも、知らせの来ていないタスクを見直す理由は無い。
- PL が頼む文にタスク名が無いので(ADR 0058-1)、サブエージェントは、どのカードを動かすかを知らない。
- 2026-11-24 の記録: agent-config は、カード1枚のために、リモートのブランチ約90本を調べ、ツールを24〜36回呼び、1分〜1分40秒。LogiFee は、チケットを1件ずつ全部読む所だけで5分39秒、全体で7分36秒(LogiFee の 3016 で一覧1回になる前)。
- 0095(ブランチ claude/0095-prompt-structure-review-criteria-cac600)が `team-kanban` と `task-team-lead` の見出しを組み直しているので、行は 0095 をマージした後の main から直す。
- 進み具合を聞かれたときの全部の書き直しを残すのは、チームの知らせを通らない変化(LogiFee の開発者コンソールに入った新しい報告・ほかの PC の PL がしたこと)を、利用者が見るときにかんばんに入れるため(ADR 0096-1 の捨てた案2)。
