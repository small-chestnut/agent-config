## ゴール

`.claude/rules/global-claude-md.md`(全体の CLAUDE.md の「なぜ」の文書)の原則6 の目指す状態が、行の位置でなく冒頭を指している。0051 で直した全体の CLAUDE.md の「返答は、最初に結論が分かり…」「返答は、結論から書いている。」と同じ向きにする。目指す状態の書き換えは、利用者が合意した(PL の問い「「なぜ」の目指す状態を「冒頭の1行」から「冒頭」に替えてよいですか?」に「52をタスクにして、やって」と答えた)。

なぜ: 0051 で、規則は行の位置や数といった形でなく、守りたい中身を指すことにした。「なぜ」の文書にだけ「冒頭の1行」が残ると、規則と「なぜ」がずれる。0051 の SE が見つけた。

範囲外: 原則6 のほかの目指す状態。

## 受け入れ条件

1. `.claude/rules/global-claude-md.md` の原則6 に、目指す状態「結論は、利用者が必ず読む冒頭にある規則になっている」がある。
2. `.claude/rules/global-claude-md.md` で「冒頭の1行」を含む行が0件。
3. 原則6 のほかの目指す状態(スクロール・字の数・既に目にしたもの)と、その下の行は変わっていない。
4. `python -m unittest discover -s tests` が 71 件とも通る。
