# 0052-why-first-line

ステータス: 未着手

## ゴール

`.claude/rules/global-claude-md.md`(全体の CLAUDE.md の「なぜ」の文書)の原則6 の目指す状態「結論は、利用者が必ず読む冒頭の1行にある規則になっている」が、行の位置でなく、冒頭を指している。0051 で直した全体の CLAUDE.md の「返答は、最初に結論が分かり…」「返答は、結論から書いている。」と同じ向きにする。目指す状態の書き換えなので、利用者の合意が要る。

なぜ: 0051 で、規則は行の位置や数といった形でなく、守りたい中身を指すことにした。「なぜ」の文書にだけ「冒頭の1行」が残ると、規則と「なぜ」がずれる。0051 の SE が見つけた。

範囲外: 原則6 のほかの目指す状態。
