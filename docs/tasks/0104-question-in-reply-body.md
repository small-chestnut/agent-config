## 難しさ

- SE: 高(アプリの指示とぶつかる所を、どの文書で・どの形で直すかを決める仕事)

## ゴール

アプリの次の一手の枠(wrap_up)に質問を出すセッションでも、返答の本文が全体の CLAUDE.md の形(結論・水平線・補足・水平線・質問)を守り、質問が本文の最後に出るようにする。

範囲外: アプリの wrap_up の指示そのもの(agent-config からは変えられない)。

## 要件

### R1 枠に質問を出しても、本文に2本目の水平線と質問を書く

- 要件: wrap_up の枠に質問を出すターンでも、返答の本文を、結論・水平線・補足・水平線・質問の形で書く。
- なぜ: 利用者が、0103 の SE の返答が「概要（横線）補足（横線）質問」の形を守っていないと指摘し、直すのをタスクにした(2026-11-27、PL の会話)。0103 の SE の会話では、wrap_up の枠に質問を出した2つの返答(「LogiFee で SE を開始するたびに…」「「向き」とは…」)で、本文に2本目の水平線と質問が無く、1つ目は水平線が1本も無かった。wrap_up の道具の説明は、枠に出した質問を本文に書かないよう指示している。PL が本文にも書くよう伝えた後の返答は、形を守った。
- 受け入れ条件 R1-1: Remote Control につながっていない子セッションが、wrap_up の枠に質問を出したターンで、本文の最後に、2本目の水平線とその下の質問がある。

### 分けたタスク

### 決まっていない問い

- 直し方: 全体の CLAUDE.md の「質問は、補足の下にもう1本水平線を引いて、その下に書く。」の行を直すだけにするか、本文に質問が無いまま止まるのを止めるフックも足すか。
