# 0080-fix-0079-rule-placement

ステータス: 未着手

## ゴール

0079 で入れた規則と「なぜ」の、次の3か所が直っている。

1. `.claude/rules/global-claude-md.md` に、支える規則がもう無い目指す状態「用語に意味を添える時を、AI に見分けられない条件で決めていない規則になっている」とその下の1行が無い。消したわけは ADR 0079-1 にある。
2. 全体の CLAUDE.md の「IT やその分野の用語がある概念は、和語や一般の語に言い換えていない。(ADR 0079-2)」と「用語の無いものは、辞書どおりの意味の語を組み合わせて指している。(ADR 0079-2)」が、利用者に向けて書く文だけでなく、仕様・チケット・skill の文にも当たる所にある。
3. 原則2の、ファイル名・行番号・コマンド名・エラーメッセージを添える行の条件が、用語の無いものを語の組み合わせで指したときにも当たる。

なぜ: 0079 の SE が、main に入った後に読み直して見つけた。
- 1は、決まりを書く文書には今の決まりだけを置く、に反する。
- 2は、2行が原則2の下にあり、原則2は利用者に向けて書く文にだけ当たる。LogiFee で作った呼び名が広がったのは、仕様・チケット・skill を通ってだった。
- 3は、今の「用語だけでは」が、用語の無いものに当たらない。

SE は、0079 で skill `prompt-structure` を読まずに規則の案を書いていた。

範囲外: 0079 で決めたこと(ADR 0079-1・0079-2)そのもの。
