## 基本の直し方

- `### 目指す状態: X` は、`## 目的: X` にする(文も末尾の番号もそのまま)。
- 元の `## 目的: …`(抽象的な目的)は消す。下に見出しの無い目的の規則は、すぐ上の目的に移す。
- 規則の行と、行の末尾の番号は、下の「直すもの」のほかは変えない。
- 下の「直すもの」は、この直し方でつながらない所だけ。
