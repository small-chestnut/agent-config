# ゴール

決まりの文書(`claude/CLAUDE.md`・`claude/skills/*/SKILL.md`)と「なぜ」のファイル(`.claude/rules/*.md`・`claude/skills/*/CLAUDE.md`)の規則の行が、どれも、することを肯定形で書いた行になっている。規則の書き方の skill(`prompt-structure`)に、規則は、することを肯定形で書くという規則がある。その「なぜ」(否定形は止めたいものを並べきれず、行数が膨らみ続け、書き漏らしたものは止まらない)が、ADR 0027-1 と `claude/skills/prompt-structure/CLAUDE.md` に残っている。

範囲外: 見出し(原則・目的・目指す状態)と、述語は肯定で、文の途中にだけ否定がある行(「〜ず、〜している」「〜ではなく」「〜無ければ」など)。

# 受け入れ条件

main(ecaf6ac)からの差分で言う。「否定形の行」は、箇条書きの行(「- 」で始まる行。コードブロックの外)で、「。」で区切った文のどれかが、末尾の括弧書きを除いて「ない」「ず」「避ける」「無い」「ません」で終わる行。

1. 決まりの文書と「なぜ」のファイルに、否定形の行が無い(下の「確かめの手順」が 0 を出す)。
2. 否定形の行だった 77 行は、それぞれ、設計の「書き換える行」の表のとおりに、新しい行に替わっているか、消えている。

4. `claude/skills/explain-to-non-experts/SKILL.md` の「- 出すものは、その世界で当たり前にあるものだけ。」が、「- 出すもの・決まりごとは、その世界で当たり前にあるものだけ。」に替わっている。

# 設計

決まりの文書と「なぜ」のファイルだけの変更。`SKILL.md` と `claude/CLAUDE.md` は決まりの文書そのものが仕様なので、`docs/specs/` は作らない。

ADR 0027-1 を提案した。足す規則の行に「(ADR 0027-1)」を付ける。書き換える行のうち ADR の番号が付いた行は、番号を残す。書き換える行とその見出しに付いた ADR は、0005-1・0006-2・0009-1・0009-3・0010-1・0010-2・0012-1・0012-2・0022-2・0024-1・0024-2。どれも、行の意味を変えずに肯定形にするので、決定は変わらない。

書き換えの決まり:

- 否定形の行は、することを書いた肯定形の行に替える。
- 同じ見出しか、同じ文書のほかの行が、することをすでに肯定形で書いていれば、その行を消す(表の「重なる所」の列)。
- 前の形を書いた行(「〜に戻していない」など)は、今の形を書いた行に替えるか、消す。
- 1つの行の中に、否定の文と肯定の文があれば、否定の文だけを消すか替える。

出典: Anthropic のプロンプトの手引き「Tell Claude what to do instead of what not to do」(https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)。

## 確かめの手順

リポジトリの根で、次を `python -X utf8 -c` か一時ファイルで走らせる。最後の行に 0 が出れば、受け入れ条件1を満たす。

```python
import re, glob
files = ["claude/CLAUDE.md"] + glob.glob("claude/skills/*/SKILL.md") + glob.glob(".claude/rules/*.md") + glob.glob("claude/skills/*/CLAUDE.md")
paren = re.compile(r"[（(][^()（）]*[)）]\s*$")
total = 0
for f in files:
    fence = False
    for n, line in enumerate(open(f, encoding="utf-8").read().splitlines(), 1):
        if line.lstrip().startswith("`" * 3):
            fence = not fence
            continue
        m = re.match(r"^\s*- (.*)$", line)
        if fence or not m:
            continue
        for s in [x.strip() for x in m.group(1).split("。") if x.strip()]:
            while paren.search(s):
                s = paren.sub("", s).strip()
            if s.endswith(("ない", "ず", "避ける", "無い", "ません")):
                total += 1
                print(f"{f}:{n}: {line}")
                break
print(total)
```
