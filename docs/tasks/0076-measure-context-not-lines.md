# 0076-measure-context-not-lines

ステータス: 未着手

## ゴール

タスクの文(利用者の言葉のまま): 「コンテキストの量ではかって、あふれたならならばどうするか、そこまでちゃんと考えろと言いたい」

全体の CLAUDE.md の長さの決まりが、行の数ではなく、毎回読まれるコンテキストの量(字の数など)で測る形になっていて、その量を超えたときにどうするかまで決まっている。

なぜ: 今の決まりは「全体は 200 行以内」(`.claude/rules/global-claude-md.md`)。守りたいのは毎回読まれるコンテキストの量なのに、行の数で測っているので、2行を1行にまとめれば字の数は減らないまま決まりを満たせてしまう。0074 では、同じ ADR の付いた2行を1行にまとめた組を3つ作り、行の数だけを合わせた。返答の長さは既に「行の数ではなく、字の数で区切る」と決めてあり、それとも揃っていない。0074 の SE との会話で、利用者が「本質は行数ではなくコンテキスト」と指摘した。行の数を測るほかの所(`check_rule_length.py` など)も、同じずれが無いか確かめる。
