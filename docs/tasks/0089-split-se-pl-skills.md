# 0089-split-se-pl-skills

ステータス: 未着手

## ゴール

SE と PL のセッションが同時に読む規則の行が、要る場面でだけ読む skill に分かれて、減っている。

## 要件

### R1 読む場面が決まっている規則の行を、別の skill に分ける

- R1 要件: skill `task-team-se` と `task-team-lead` の規則のうち、読む場面が決まっている行(ADR の書き方と番号の付け方・仕様の形・モデルの割り当てなど)を、その場面でだけ読む別の skill に分ける。始めるのは、0088 の変更が入って、SE の動きがどう変わったかを見た後。
- R1 なぜ: 0088 で行を消した後も、同時に読む規則の行は SE が約 250 行、PL が約 200 行で、量だけで見ても多い(Anthropic の目安は、CLAUDE.md 1ファイル 200 行未満。IFScale では、指示 250 個で1世代前の Claude が守れたのは 68〜77%。https://code.claude.com/docs/en/memory ・ https://arxiv.org/html/2507.11538v1 )。残る行の大半は、ほかの仕組みが読む形の取り決めで、消すとほかのセッションが動けなくなる。行を消すことと skill に分けることを同時に入れると、後で AI の動きが変わったときに、どちらのせいか見分けられない。利用者は、次のタスクとして残すことに合意した(「チケットは書いておいてよい」)。
