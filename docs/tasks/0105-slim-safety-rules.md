## 難しさ

- SE: 高(安全の節は、行が無くて起きる損失が取り返しのつかない節で、採用した ADR 2つの理由と逆向きの依頼)

## ゴール

全体の CLAUDE.md の安全の原則の節の行を、消しても Claude の動きが変わらないか1行ずつ確かめ、変わらない行を消す。

範囲外: permissions の deny とフック(`claude/user-settings.json`・`claude/project-settings.json`・`claude/hooks/`)。

## 要件

### R1 安全の節の、消しても動きが変わらない行を消す

- 要件: 全体の CLAUDE.md(`claude/CLAUDE.md`)の「原則1: 安全」の節の行を1行ずつ確かめ、消しても Claude の動きが変わらない行を消す。
- なぜ: 利用者は、安全の文が今でも要るかを疑い、要らない行なら消したい(2026-11-28、PL の会話で「タスクにする」と答えた)。このリポジトリの命題(ほかのリポジトリで読まれる文章を少なく保つ)に沿う。
