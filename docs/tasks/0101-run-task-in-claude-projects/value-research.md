## ローカルのスレッドで、この PC の仕事ができるか

できる。ただし、次のことが付く(https://code.claude.com/docs/en/claude-projects の Run a thread on your own computer・See what needs you in Overview・Limitations)。

- Remote Control をつないだフォルダで、その PC の設定・フック・permissions のまま動く。
- スレッドは、ふつうクラウドで始まる。ローカルにするには、依頼の文で頼み、スレッドごとの許可の札に利用者が答える。ローカルだけにする設定は、書かれていない。
- PC のスリープの間は止まり、デスクトップアプリを閉じると終わる。
- 自分で始めた会話は、プロジェクトに入れられない。
- スレッドがほかのスレッドを始めることと、スレッドどうしのやりとりは、書かれていない。
- プロジェクトは、ベータ版。
- https://code.claude.com/docs/en/remote-control は、一部を要約で読んだ。

## 結論

規則を減らすためなら、移る価値は無い。

1. クラウドは、肩代わりされると言える行が 30 行(12%)で、使えるのが仕事の 26%。残りの仕事のために、今の行は消せない。
2. ローカルは、どの仕事にも使えるが、肩代わりされると言える行が 13 行(5%)に減り、利用者がスレッドごとに許可を答える手間が増える。
3. B と C の 39 行が肩代わりされても、1 の、残りの仕事のために行を消せないことは変わらない。

見直すとき: ローカルのスレッドを初めから選べて、スレッドどうしがやりとりでき、Overview に未着手のタスクも出る。または、規則の数よりも、PC を閉じても仕事が進むことを優先する。
