### 調べて分かったこと(2026-11-24)

### 設計レビュー(2026-11-24。コミット 258233d)

1. ADR 0094-1 の理由4とチケットの「調べて分かったこと」の「行なしは、速さごとに1つの large に分けた」は、試しの結果と合わない。行なしの2回目は、仕訳500枚と経費100件を1つの large にまとめている(`noline_S_2.txt` の1)。
2. 同じ所の「画面から通す large は、行が無くても増えなかった(増えない)」は、gemini と源泉の要件だけで成り立つ。速さの要件の large は会計管理の画面の表示までを確かめ、1・1・2 から 3・2・4 に増えた。行なしの3回目の、描画の回数を確かめる large は、速さを測るテストでもない(`noline_S_3.txt` の3)。
3. ADR 0094-1 の番号を付ける所が設計に無い(ADR 0006-1)。「ほかの行は変えない」のままだと、次に目指す状態「テストは、適正な量になっている」を書き換える SE は、見出しの番号から 0093-1 だけを読み、その理由7で、large の上限が今もあると読む。
4. Nit: ADR 0094-1 の理由2は、「利用者の理由」の後ろに、Claude が調べたこと(0005-1 の出典・0093-1 の理由2)を同じ番号で続けていて、どこまでが利用者の理由かが分かれていない。
