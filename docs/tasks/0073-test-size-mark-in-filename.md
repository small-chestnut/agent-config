## ゴール

全体の CLAUDE.md(`claude/CLAUDE.md`)の、タグの無いテストフレームワークでテストの大きさの印をファイル名に入れる規則が、どのフレームワークでも、印を付けたテストが流れなくならない形になっている。

なぜ: 今の規則は、ファイル名に `.medium`・`.large` を入れる形。Python の unittest の discover は、点を含むファイル名をエラーを出さずに読み飛ばすので、印を付けた中と大のテストが一度も流れなくなる(PL が手元で確かめた)。テストの大きさごとに決まった時に流す、という目指す状態に反する。0072 の SE が見つけ、0072 ではリポジトリの側だけ `medium_test_` を頭に付ける形にした(ADR 0072-1)。

範囲外: 各リポジトリのテストのファイル名の付け替え。

## 要件

### R1 印を付けたテストが、どのテストフレームワークでも拾われる

- 要件: タグの無いテストフレームワークで中と大のテストに付けるファイル名の印は、テストフレームワークがテストとして拾う名前の決まりを崩さない形。
- なぜ: `.medium`・`.large` を入れると、unittest がエラーを出さずに読み飛ばし、中と大のテストが一度も流れない。テストサイズごとに決まった時に流す(ADR 0009-3)ことができなくなる。
- 受け入れ条件 R1-1: 全体の CLAUDE.md の、タグの無いテストフレームワークの行は、中と大のテストのファイル名の頭に `medium_`・`large_` を付ける形になっている。

## 設計

### ADR

- 0073-1 タグの無いテストフレームワークでは、中と大のテストのファイル名の頭に `medium_`・`large_` を付ける(提案)。0009-2 の、ファイル名に `.medium`・`.large` を入れる所だけを置き換えるので、0009-2 は「採用」のまま残す。
- 読んだ ADR: 0009-1・0009-2・0009-3(書き換える見出しと、その前後の見出しに付いた番号)、0072-1(既にある同じ形)、0076-1・0076-2(全体の CLAUDE.md の字数)、0087-1・0087-2(規則の行の確かめ方)、0006-2(一部の置き換えの書き方)。

### 置くファイルと名前・データ

- `claude/CLAUDE.md` の見出し「目指す状態: テストサイズが、テストのタグかファイル名に書いてある(ADR 0009-2)」の下の2行目を、次の1行に置き換える(R1-1)。見出しの「(ADR 0009-2)」は残す。
  - 前: `- タグの無いテストフレームワークでは、ファイル名に `.medium`・`.large` を入れている。`
  - 後: `- タグの無いテストフレームワークでは、中と大のテストのファイル名の頭に `medium_`・`large_` を付けている。(ADR 0073-1)`
- 後の行は、規則の行の字数の数え方(`claude/hooks/check_rule_length.py` の `rule_length`)で 50 字ほどで、上限の 60 字に収まる(2026-11-17 に SE が数えた)。
- 全体の CLAUDE.md は、字数の上限 8,000 字(ADR 0076-1)に対し、2026-11-17 に 7,041 字。この行で十数字増えるだけで収まる。
- 仕様: 全体の CLAUDE.md はプロンプトそのものなので、それが仕様。`docs/specs/` には作らない。
- このリポジトリの CLAUDE.md の `medium_` の行(ADR 0072-1)は、新しい全体の規則と同じ形なので変えない。
