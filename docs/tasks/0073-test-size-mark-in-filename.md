# 0073-test-size-mark-in-filename

ステータス: 未着手

## ゴール

全体の CLAUDE.md(`claude/CLAUDE.md`)の、タグの無いテストフレームワークでテストの大きさの印をファイル名に入れる規則が、どのフレームワークでも、印を付けたテストが流れなくならない形になっている。

なぜ: 今の規則は、ファイル名に `.medium`・`.large` を入れる形。Python の unittest の discover は、点を含むファイル名をエラーを出さずに読み飛ばすので、印を付けた中と大のテストが一度も流れなくなる(PL が手元で確かめた)。テストの大きさごとに決まった時に流す、という目指す状態に反する。0072 の SE が見つけ、0072 ではリポジトリの側だけ `medium_test_` を頭に付ける形にした(ADR 0072-1)。

範囲外: 各リポジトリのテストのファイル名の付け替え。
