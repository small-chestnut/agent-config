# ゴール

`docs/用語集.md` に、規則・ADR・フック・README のどこにも出てこない語の行が無く、残す行の「意味」の欄は、その語が何かを言う一言だけで、ほかの文書にある規則(誰が・いつ・何をする)の言い直しを持たない。

範囲外: 「コードの名前」と「画面に出す字」の欄と冒頭の説明の文を変えること、用語集の規則(`claude/CLAUDE.md` 原則3)と skill を変えること、ほかのリポジトリの用語集。

# 受け入れ条件

1. `docs/用語集.md` が、設計の手順1 の文のとおりである。
2. `docs/用語集.md` に、業務の言葉「ADR の対象」「ADR の参照」「置き換える ADR」「大きさの印」の行が無い。
3. `docs/用語集.md` の残す行の「業務の言葉」「コードの名前」「画面に出す字」の欄と、冒頭の見出しと説明の文は、変える前と同じである。
4. `docs/用語集.md` と、この記録のほかのファイルは変わっていない。

# 設計

書き換える `docs/用語集.md` の行のうち、ADR の番号が付いているのは「モジュール」(0012-1)と「公開の入口」(0012-2)の「意味」の欄だけ。番号が付いていた文は、`claude/CLAUDE.md` 原則3 と skill `module-layout` にある規則の言い直しなので消し、番号も一緒に消す。どちらの決定も変えない。ADR は書かず、設計レビューは無く、PG に回す。用語集はモジュールではないので、仕様は直さない。新しい名前は無い。

利用者が SE の問いに答えて決めたこと: 使われていない行を消し、残す行の「意味」の欄も一言にする。規則・ADR・フックのどこにも出てこない語(ADR の対象・ADR の参照・置き換える ADR・大きさの印)の行は消す。「意味」の欄の、ほかの文書の規則の言い直し(誰が・いつ・何をする)は消す。

消す行の4語は、`claude/`・README・`docs/adr/`・`docs/specs/`・`tests/` のどこにも出てこない(`grep -rF` で数えて0)。「意味」の欄から消す文は、どれも次の文書に同じ規則がある。

| 業務の言葉 | 消す文 | 同じ規則がある文書 |
|---|---|---|
| タスクの番号・タスク名 | PL が振る・タスク名の頭に付く・番号とハイフンと英語の短い名前・記録・子セッション・ブランチの名前に使う | skill `task-team-lead` の「タスク名は、…」「タスクの番号は4桁の連番で、PL が振る。」と、子セッション・記録の名前の行 |
| ADR | 捨てた案と、理由を残す | skill `task-team-se` の ADR の節 |
| 仕様・仕様の「ADR」の節・機能の節 | モジュール1つに1ファイル・動きを変える変更で直し、SE が設計の最初に読む・SE はコードを書き換えるとき、ここの ADR も読む・用語集の言葉で書いた1文 | skill `task-team-se` の仕様と ADR の節 |
| 次に回すタスク | PL の報告の最後に並べる | skill `task-team-lead` の「起こすまでのタスクは、報告の最後に…」 |
| 命題 | `docs/概要.md` の冒頭か、…・agent-config では README の「目的: 」の行 | skill `task-team-lead` の「命題は、…」と、このリポジトリの CLAUDE.md の1行目 |
| 壁打ち・タスクの文・PL の答え | 決まった動きに戻すもののほか・PL は…言い切り、チームは起こさない・壁打ちの後は…まとめた文・決定ではなく材料だと添えて SE に渡す | skill `task-team-lead` の壁打ちと子セッションに渡す文の行 |
| テスト一覧・テストの基準 | SE が書き、PG はそのとおりに作る・QA がレビューで比べる | skill `task-team-se`・`task-team-pg`・`task-team-qa` |
| テストの大きさ | 小は…速さの計測・既定はグローバルの CLAUDE.md 原則3 | `claude/CLAUDE.md` 原則3 のテストの大きさの節 |
| モジュール・公開の入口 | 画面のナビの行き先ごと…(ADR 0012-1)・入口の外は…(ADR 0012-2) | `claude/CLAUDE.md` 原則3 と skill `module-layout` |
| リポジトリの決まり | agent-config の規則とぶつかったら、こちらに従う | `claude/CLAUDE.md` の冒頭 |
| 確かめのコマンド・確かめのコマンドの一覧・中身の印・ターンの始めの印 | この頭で始まるコマンドが通れば…・無いリポジトリでは Stop フックが何もしない・コミットしても…変わらない・Stop フックはこれと…比べる | 仕様 `docs/specs/require_verify_before_stop.py.md` |
