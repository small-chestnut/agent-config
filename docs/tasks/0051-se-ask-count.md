# 0051-se-ask-count

ステータス: 未着手

## ゴール

SE が利用者に聞く問いの数が、分からないことの数に合っている。

今の skill `task-team-se` の「問いは、1行で答えられるものを3〜5個、AskUserQuestion で。」は、分からないことが1つでも問いを3つ作らせ、利用者の答える手間を増やす。AskUserQuestion は1回に4問までなので、5個は1回では聞けない。この行は、説明し直すときに利用者が止まっている所を探す、全体の CLAUDE.md の「止まっている所を確かめる問いは、1行で答えられるものを3〜5個にしている。」を写したもので、目的が違う。

範囲外: 全体の CLAUDE.md の「止まっている所を確かめる問い」の行(止まっている所を探す目的には、3〜5個が合っている)。
