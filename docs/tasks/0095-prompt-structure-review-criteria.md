## 要件

### R1 組んだ決まりは、どの段でも、すぐ上の段に合っているかを判断できる

- 要件: skill prompt-structure を読んだ Claude が組む決まりは、規則から命題までどの段でも、すぐ上の段に合っているかを判断できる。原則が1語だけの見出しと、規則の言い直しの見出しを作らない。
- なぜ: 利用者が、規則から上へ「状態に合っているか・目的に・原則に・命題に」と確かめるとき、途中の段で判断できないと、意図がそこで途切れる。

### R2 段は4段にする

- 要件: 決まりの段は、命題 → 原則 → 目的 → 規則の4段にし、目指す状態の段を無くす。
- なぜ: 段が少ない方が、Claude が組みやすい。
- 受け入れ条件: 壁打ちのあとに書く。

### R3 今ある文書も4段に直す

- 要件: agent-config に今ある文書(全体の CLAUDE.md・rules・skill。目指す状態の見出し 125)を4段に組み直す。段の見出しを見るフック(`ask_about_written_lines.py`)も4段に合わせる。利用者は、フックの問いの文も変わると聞いたうえで「直す」と答えた。
