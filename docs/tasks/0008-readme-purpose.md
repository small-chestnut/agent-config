# ゴール

README.md の冒頭に、agent-config の目的を書く。目的は、PL と利用者で合わせた次の文。

「新しいシステムを開発するとき、そのリポジトリの CLAUDE.md を作りこまなくても、agent-config の設定を読めば、すぐに AI 駆動開発に最適な環境ができること。」

利用者の言葉:「私は、このリポジトリを読んでいれば、なにか新しいシステム開発をするときに、リポジトリのclaude.mdを作りこまなくても、このagent-configの設定ですぐにAI駆動開発に最適な環境ができること　それを目指している」。「このリポジトリを読んでいれば」は、AI が agent-config の設定(install で入れた CLAUDE.md・skill など)を読む、という意味。

範囲外: README の最初の `##` より後の節と、CLAUDE.md・skill・hooks の中身を、この目的に合わせて直すこと。

# 受け入れ条件

1. README.md の「# agent-config」の次の段落が、「目的: 」に続けて、ゴールの文をそのまま書いた1行である。
2. README.md の最初の `##` より前に、「安全設定テンプレート」の語が無く、agent-config が置くものとして、全プロジェクト共通の指示(CLAUDE.md・AGENTS.md)・作業ごとの手順(skill)・安全設定の3つが書いてある。
3. README.md の最初の `##`(「## 構成」)から後は、変わっていない。
4. このリポジトリの CLAUDE.md は、変わっていない。

# 設計

書き換えるのは README.md の1〜4行目(見出しと最初の段落)だけ。そこに ADR の参照は付いていないので、読む ADR は無い。新しい名前は無いので、用語集は変えない。する人は、どの手順も PG。

## 手順: README.md の冒頭を書き換える

README.md の次の2行(3〜4行目)を、

```
AI コーディングエージェント(Claude Code / Codex CLI)の安全設定テンプレート。
エージェントによる意図しない破壊的操作を、設定レベルで機械的にブロックする。
```

次の文に置き換える。「# agent-config」の行と、その後の「## 構成」から後は変えない。

```
目的: 新しいシステムを開発するとき、そのリポジトリの CLAUDE.md を作りこまなくても、agent-config の設定を読めば、すぐに AI 駆動開発に最適な環境ができること。

そのために、AI コーディングエージェント(Claude Code / Codex CLI)の設定として、次の3つを置く。

- 全プロジェクト共通の指示(`CLAUDE.md`・`AGENTS.md`)
- 作業ごとの手順(skill。呼ばれたときだけ読み込まれる)
- 意図しない破壊的操作を、設定で機械的に止める安全設定(deny ルール・hooks・サンドボックス)
```

main に README の変更が先に入っていて衝突したら、main を取り込み、冒頭はこの文に、ほかの節は main の側に揃える。
