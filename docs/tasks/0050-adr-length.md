## ゴール

ADR の捨てた案と理由に何をどれだけ書くかは、行数の上限ではなく、書く中身で決まっている。

- なぜ: skill `task-team-se` の「捨てた案と理由は、各1〜3行。」(`claude/skills/task-team-se/SKILL.md` 154行目)には、行数そのもの以上の理由が無い。元は 2026-10-15 のコミット abe32d0 で全体の CLAUDE.md に入った「書くこと: 日付・決めたこと・捨てた案・理由、各1〜3行。」で、参考は Claude Code 公式の CLAUDE.md の目安と LogiFee の形だった。親の目指す状態「ADR は、決まった形で1つのフォルダにある」も形を言うだけで、ADR の番号も付いていない。
- なぜ(2): 読み方が2通りに分かれる。別のリポジトリのタスク 0012 では、SE が「理由は全部で3行まで」と読み、ADR の4つ目の理由を消した。agent-config では、ADR 47件のうち10件の理由が4項目以上ある(ADR 0049-1 は7項目)。根拠が本当に4つある決定でも、行数で1つ削られうる。これは、全体の CLAUDE.md 原則3 の目指す状態「利用者が決めたことと、利用者の「なぜ」が、リポジトリに残っている」に反する。
- 利用者の考え: 「3行まで」に、「3行まで」以上の理由がないなら、見直すべき規則。

範囲外: 既にある ADR の書き直しと、ADR のほかの形(冒頭の3行・節・決めたことの1行)。
