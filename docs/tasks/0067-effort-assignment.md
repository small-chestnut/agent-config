## ゴール

チームの役割のモデルと effort を決める作りを、浅い判断の SE 本人が自分の難しさと Fable に替える時を決めない形にし、SE が作った本質的におかしな設計を QA の設計レビューが利用者より先に止める形にする。

範囲外: SE が新しい作りを設計する前に既にある機能と ADR を探す手順(R-0718 の誤りの原因の候補として PL に別に知らせた)。LogiFee の R-0718 の作業そのもの。
