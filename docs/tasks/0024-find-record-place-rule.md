# ゴール

PL は、リポジトリの決まりが記録の置き場をパスの形で書いていなくても(「結果をチケットに書いて終えている」など)、作業の結果を書く所の決まりと、それが指す手順の文書から置き場と書き方を読み、従う。置き場がファイルでなくても、SE・PG・QA は記録を読み書きでき、PL はマージできないときにリポジトリの決まりの渡し方に従う。

範囲外: LogiFee を変えること、CLAUDE.md・rules・skills のどこにある決まりでも置き場として探すこと、タスクの番号の振り方と、ADR の置き場と番号の決まりを変えること。

# 設計

文書だけの変更。各 SKILL.md がそのモジュールの仕様なので、仕様は SKILL.md を直す。

書き換える行そのものと、その見出しには ADR の番号が無い。足す行の隣には、task-team-lead の85〜92行目(記録を消す・マージ)の 0009-3・0022-2 がある。読んだ ADR は 0004-1・0022-2。新しい決定は ADR 0024-1(置き場の読み方)と 0024-2(ファイルでない記録の書き方)で、状態は「提案」。マージの行は ADR 0004-1 の決めたこと3(リポジトリの決まりに従う)を書き出したものなので、新しい ADR を作らず 0004-1 を付ける。

タスクの番号の振り方は変えない。リポジトリが番号を決めていれば(LogiFee の管理番号など)、ADR 0004-1 の決めたこと3のとおりリポジトリの方に従う。

85行目(push の前に記録と記録のフォルダを消す)は変えず、86行目と同じ形で、受け入れ条件 9 の例外の行を86行目の次に足す。ファイルでない記録から指す `docs/tasks/<タスク名>/` の図は、これで消えない。

## 設計レビュー

- 受け入れ条件 2(タスクの番号を、置き場の手順の文書が決める番号にする)は、ADR 0004-1 の決めたこと2(タスクの番号は PL が振る4桁の連番で、ADR の番号はタスクの番号から作る)と食い違う。0004-1 を置き換える ADR が無く、32行目の「(ADR 0004-1)」もそのまま残る。チケット番号が `LF-123` なら ADR の番号も `LF-123-1` になり、範囲外とした「ADR の番号の決まり」が変わってしまう。
- 受け入れ条件 9(SE への prompt の「記録のパス」を「記録の置き場」にする)の行に「(ADR 0024-1)」が無い。同じ言い換えをする受け入れ条件 7・22 には付いている。
