# ゴール

全体の CLAUDE.md(`claude/CLAUDE.md`)と PL の skill(`claude/skills/task-team-lead/SKILL.md`)の、利用者の「なぜ」の規則が、どちらも次の一通りにしか読めない。利用者の「なぜ」は、利用者が言った理由と、利用者がはっきり同意した理由の両方で、その内容だけを、まとめた文で残す。その「なぜ」(原文ママでは、利用者が一番やりたいことと言葉がずれうる。壁打ちで同意した理由を入れない、という選択肢はそもそも無い)が、それぞれの「なぜ」の置き場に残っている。

範囲外: 「なぜ」の置き場の決め方そのもの。
