# ゴール

全体の CLAUDE.md(`claude/CLAUDE.md`)と PL の skill(`claude/skills/task-team-lead/SKILL.md`)が、利用者の「なぜ」を出どころ(言った人・同意の仕方)で絞り込まず、まとめた文で残す・渡す形になっている。PL は、壁打ちで固まった要件と「なぜ」のまとめを、SE に送るのと同時に利用者に見せ、OK を待たず、ずれを言われたら直しを SE に送る。その「なぜ」(原文ママでは、利用者が一番やりたいことと言葉がずれうる。壁打ちで固めた要件が SE に正しく届いてほしく、そのために利用者に「タスクにして」以外の手間を増やしたくない)が、それぞれの「なぜ」の置き場に残っている。

範囲外: 「なぜ」の置き場の決め方そのものと、PL の答えの渡し方。

# 設計

決まりの文書だけの変更。`claude/CLAUDE.md` と `SKILL.md` は、決まりの文書そのものが仕様なので、`docs/specs/` は作らない。書き換える行とその見出しに ADR の番号は無い。足す行には ADR を付けない。ADR は書かない。

`claude/CLAUDE.md` の見出しの「利用者が言った理由」も出どころで絞り込む言葉なので、「利用者の「なぜ」」に替える。
