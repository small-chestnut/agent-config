## ゴール

全体の規則(`claude/CLAUDE.md` と `claude/skills/*/SKILL.md`)から、同じ人が同じ場面で読む別の行と中身が重なる行と、振る舞いを変えない行が、消えるか1行にまとまっている。

なぜ: 毎回読まれる規則は、1項目の効きが薄まらない量にしたい。同じ規則が2か所にあると、片方だけ直したときに食い違う。利用者は、どれを消すかを SE の裁量に任せた(「あなたの裁量でせよ」)ので、壁打ちをせずに設計した。

範囲外: 「なぜ」を書く文書(`claude/skills/*/CLAUDE.md`・`.claude/rules/`)、全体の CLAUDE.md の安全の原則の節、重なりではない言い回しの直し。
