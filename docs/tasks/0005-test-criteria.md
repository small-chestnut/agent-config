# ゴール

task-team で、どのテストを作り、どのテストを作らないかと、テストの大きさ(小・中・大)の決め方を、SE・PG・QA の skill と README に入れる。SE が設計の節に受け入れ条件ごとのテストの大きさを書き、PG はそのとおりに作り、QA はレビューで多すぎるテストと足りないテストを指摘する。

範囲外: 既にあるテストを、この基準に合わせて足す・消すことと、基準をフックやテストで検査すること。
