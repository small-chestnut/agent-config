  ```python
  """入出金1件の消込の状態を返す。"""


  def clearing_status(payment_amount, allocations, imported_ids):
      """payment_amount: 入出金の額。
      allocations: 先方のデータにある、その入出金の割当の行(id と amount)。
      imported_ids: こちらのシステムに入った割当の行の id。
      """
      if not allocations:
          return "未消込"
      if all(a["id"] in imported_ids for a in allocations):

      return "一部消込"
  ```

### 設計への問い(PG)

- Windows で `shutil.which("claude")` が返す `claude.CMD`(npm の shim)に、`QUESTION + "

" + 規則の1行` を渡すと、改行から後ろが cmd.exe に切られ、セッションに規則の1行が届かない。K1 を本物の claude で流したら、3つの答えがどれも「1行が届いていません」だった(K2 は改行の無い文なので通った)。同じ引数を `claude.exe`(`<npm のフォルダ>
ode_modules\@anthropic-ai\claude-codein\claude.exe`)に直接渡すと、改行も届いた。
- 設計は、起動する `claude` の探し方を `shutil.which` とだけ決めている。次のどれにするか決めてほしい。
  - A: `find_claude` が `.cmd` を返したら、同じ npm フォルダの `node_modules/@anthropic-ai/claude-code/bin/claude.exe` に置き換える(npm の入れ方に依る。置き換え先が無ければ `.cmd` のまま)。

  - C: A か B のうち、決めた方のテスト(一覧に無い)を足す。
