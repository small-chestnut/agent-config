# 0078-tool-term-in-rules

ステータス: 未着手

## ゴール

`claude/` の下の規則と「なぜ」の文書が、IT の用語「ツール」を「道具」と言い換えていない。

なぜ: 全体の CLAUDE.md(ADR 0044-1)は、IT の用語を例えや作った呼び名に替えないと決めている。規則の文が言い換えていると、それを読んだ AI が同じ言い換えを利用者への説明に持ち込む。利用者は、AI が「データソース」を「読み元」、「スクリプト」を「道具」、「回帰テスト」を「確かめ」と言い換えたくなるのではと問い、PL がそう答えた。

範囲外: 一般の動詞としての「確かめる」。
