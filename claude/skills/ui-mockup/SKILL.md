# 原則1: 人間側の最適化 ― 利用者が、AI の出力と作業の今を、少ない負担で正確につかみ、自分の意図どおりに AI を動かせる

## 目的: 図は、実装後に開いたときと同じ見た目で、利用者が実装を待たずに提案を判断できる

- 色・フォントサイズ・コンポーネントの形は、そのプロジェクトの既存の画面に合わせる。
- サンプルデータは、その業務で実際にありそうな値にする。
- 画面のどこにあるかが分かる範囲まで描く。

## 目的: 何が変わるかが一目で分かる

- 既存の画面を変えるときは、変更前と変更後を並べ、変わる箇所に印を付ける。
- 画面が複数あるときは、利用者が操作する順に並べる。
