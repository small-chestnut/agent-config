原則がぶつかったときは、番号の小さい方を先にする。

# 原則1: 一貫

## 目的: 同じ規則を2か所で直す手間と、片方だけ直した食い違いが無い

### 目指す状態: 規則を1か所にだけ置く行が、この skill に残っている

# 原則2: 簡潔

## 目的: 規則が、止めたいものの数だけ増えず、書き漏らしたものも止める

### 目指す状態: 規則を肯定形で書く行が、この skill に残っている

# 原則3: 整合

## 目的: 利用者が、規則と目的の矛盾を探して AI に突きつけずに済む

### 目指す状態: 目的に反する規則を直すときも、Claude が規則に手を入れる行が、この skill に残っている

- 「違う」と言われたときだけだと、全部を見ていない利用者が、矛盾を探す役を負う。
