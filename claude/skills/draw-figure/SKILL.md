# 原則1: 理解

## 目的: 利用者が、図を見て中身を掴める

### 目指す状態: 図は、会話の中ですぐ見られる

- 図は、会話の中に表示される形(HTML か SVG)で出している。
- 会話の中に表示できない環境では、HTML ファイルに書き出し、開くためのパスを示している。
- 図は返事の冒頭(tl;dr があればその直後)にある。

### 目指す状態: 文章のどこが図のどこの話かが分かる

- 文章は、図に見えている文字か、図に振った番号で、どの部分の話かを示している。
