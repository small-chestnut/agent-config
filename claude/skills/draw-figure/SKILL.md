# 原則1: 理解

## 目的: 利用者が、図を見て中身を掴める

### 目指す状態: 図は、会話の中ですぐ見られる

- 図は、会話の中に表示される形(HTML か SVG)で出している。
- 会話の中に表示できない環境では、HTML ファイルに書き出し、開くためのパスを示している。
- 図は、結論の直後、補足の文より先にある。

### 目指す状態: 文章のどこが図のどこの話かが分かる

- 文章は、図に見えている文字か、図に振った番号で、どの部分の話かを示している。

## 目的: 利用者が、サブタスクの進捗を、図をひと目見て掴める

### 目指す状態: 進捗の図は、いつも同じ形をしている(ADR 0035-1)

- サブタスク1つを箱1つにし、依存先のサブタスクから矢印を引いている。
- 1本道のサブタスクも、枝分かれするサブタスクも、同じ描き方にしている。
- 済み・作業中・まだは、箱の色で分けている。
- 「いまここ」のような、今の位置を指す字は書いていない。
- 箱の字は、サブタスクの名前だけにしている。
- 図の下に、3つの色が何かを示す見本を1行で添えている。
- チケットの進捗からは、サブタスクの行を箱、`依存: ` を矢印、サブタスクのステータスを色にしている。

### 目指す状態: 同じ進捗からは、同じ配置の図が出る(ADR 0035-2)

- 図は、mermaid の `flowchart TD` の文で書き、配置は mermaid に任せている。
- 会話の中では、HTML で mermaid@11 を esm.sh から読み込んで描いている。
- 済みの箱は、`classDef` で `fill:#EAF3DE,stroke:#3B6D11,color:#27500A` にしている。
- 作業中の箱は、`classDef` で `fill:#FAEEDA,stroke:#854F0B,color:#633806` にしている。
- まだの箱は、`classDef` で `fill:#FFFFFF,stroke:#888780,color:#444441,stroke-dasharray:4 3` にしている。
