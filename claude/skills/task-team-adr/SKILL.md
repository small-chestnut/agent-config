# 原則1: AI 側の最適化 ― Claude が、どのリポジトリでも、要るものだけを読み、手戻りなく、作業を終えられる

## 目的: 後から変えにくい決定は、採用した ADR にある(ADR 0004-1・0007-1)

- ADR の直しを頼まれたら、「提案」のまま直すか、「却下」にする。(ADR 0085-7・0086-1)

## 目的: ADR は、決まった形で1つのフォルダにある

- 保存先は `docs/adr/<ADR の番号>-<英語の短い題>.md`。(ADR 0004-1)
- ADR の番号は `<タスクの番号>-<そのタスクの中の連番>`(例: `0004-1`)。(ADR 0004-1)
- 冒頭は、題の見出しと、「状態: 」「日付: 」「対象: 」の3行。
- 節は、決めたこと / 捨てた案 / 理由。
- 1つの ADR には、決定を1つだけ書く。(ADR 0006-3)
- 決めたことは、どの決定かが分かる1行。詳しい文は skill などに任せる。(ADR 0006-3)
- 状態は、提案・採用・却下・廃止・置き換え済み(<ADR の番号>)。

## 目的: 置き換えた古い ADR へ、新しい ADR からたどれる(ADR 0006-2)

- 決定を変えるときは、新しい ADR を書いて「対象: 」の次に「置き換える: <古い番号>」の行を足し、古い方の状態を「置き換え済み(<新しい番号>)」にする。
- 古い ADR の決定の一部だけを置き換えるなら、新しい ADR に「置き換える: <番号> の<決めたことの番号>」と書き、古い方の状態は「採用」のまま残す。
