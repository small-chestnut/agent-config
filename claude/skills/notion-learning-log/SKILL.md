# 原則1: 一貫性

## 目的: 学習記録が、どのセッションで書いても、Notion の運用ルールのとおりになっている

### 目指す状態: 学習記録を書く・直す前に、運用ルールのページを読んでいる

- 「📋 学習記録 運用ルール」(https://app.notion.com/p/3a6470fb206881999dfbe0642d13b691)を開いて読んでいる。
- 記事を作るときは、テンプレート「記事」(template_id 400470fb-2068-8086-8972-e767a408aba1)を当て、本文が入ったのを fetch で確かめてから、運用ルールのとおりに中身を書いている。
