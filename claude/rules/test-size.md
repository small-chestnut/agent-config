## 目的: 遅いテストを待たずに、その時に要るテストだけを実行できる(ADR 0009-2)

- medium と large のテストには、テストフレームワークのタグで `medium`・`large` を付ける。
- タグの無いテストフレームワークでは、medium と large のテストのファイル名の頭に `medium_`・`large_` を付ける。(ADR 0073-1)
