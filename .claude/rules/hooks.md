# 原則1: 強制

## 目的: 例外の無い決まりを、モデルの判断で破らせない

### 目指す状態: 「短く」と書くだけでは通る長い決まりの行を、フックが止めている

- 字数は、`check_rule_length.py` が数えて止めている。

### 目指す状態: 書いている最中には気づけない冗長さと例の並びに、1か所を指して問い返している

- `ask_about_written_lines.py` は、足した行を1か所ずつ指して問い返している。
- 例の並びは、書いた例にしか効かず、穴を例で塞ぐと規則の束ができる。

### 目指す状態: 誰も読み返さない自動メモリにも、プロンプトと同じ数えと問いが掛かっている

- 自動メモリは Claude が一人で書き、利用者もほかのフックも見ていない。

### 目指す状態: Bash や PowerShell で書いたプロンプトも、素通りしていない

- `check_rule_documents_changed_by_shell.py` が、シェルで書いた行にも同じ2つを掛けている。
- コマンドに出ないパスへ書くスクリプトは、cwd のリポジトリの分だけ見えている。

### 目指す状態: 取り込んだだけの決まりの行を、Claude に書き換えさせない

- 取り込む git コマンドで git が持ってきた行には、字数の数えも問いも掛けていない。
- 取り込んだ行は、既にレビューを経た決定で、直すと要らない差分ができる。

### 目指す状態: ほかの呼び出しが書いた行を、シェルの行として直させない

- Edit・Write・MultiEdit が書いた行は、シェルの後に問わない。(ADR 0041-1)
- ほかのセッションの行を直しに行くと、その作業とぶつかる。

### 目指す状態: モデルの判断で、確かめずにターンを終えない

- ターンの終わりの確かめは、`require_verify_before_stop.py` が見張っている。
- ツールを使わずに8回続けて止めると、Claude Code がターンを終わらせる。

### 目指す状態: 文字列のパターンで書けない履歴を消す push も、止まっている

- その push は、`block_history_erasing_push.py` が止めている。
